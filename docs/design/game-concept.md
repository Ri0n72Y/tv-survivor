# Game Concept

> 状态：讨论中。
>
> 本文件描述 **tv-survivor 想成为怎样的游戏**。它位于版本 Requirement 之前：Design 可以保留尚未进入开发范围的设想；Requirement 将在设计收敛后，从这里及相关 Design 中抽取当前版本要实现的 Scope。
>
> 本版只整合已经存在于 `array-exploration.md` 与 `world.md` 中的设计共识。没有得到现有设计材料支持、或仍需要选择的内容，统一放在“待讨论问题”中，不以当前代码实现反推设计答案。

## 1. 核心概念

这是一个以 **类幸存者实时自动战斗** 与 **抽象结构探索** 共同构成核心循环的 2D 游戏。

玩家不只是在战斗中生存和成长，也需要在战斗之间读取一个信息不完整、持续变化的结构空间：判断路线、资源与风险，决定继续深入、改变目标或及时止损。结构层的选择会改变局部战斗，而战斗结果会返回结构层并改变之后的局势。

题材外壳采用日式西幻异世界与“勇者”叙事。世界中的魔法并非纯粹祝福，而是一种围绕危险物质“魔素”形成的使用、排出和制度化处理技术；教会、贵族、王国、魔族等社会结构围绕这种资源建立秩序、垄断、战争与意识形态。

主角以被召唤的救世勇者身份进入这个世界。表面上，这是从普通消耗品跃升为拥有力量与使命的英雄幻想；随着游戏推进，主角逐渐发现“勇者”也可能只是被制度赋予神圣包装的消耗品，并在依赖个人力量解决结构性问题时面临复制旧压迫关系的风险。

## 2. 核心体验承诺

### 2.1 战斗中的力量成长

战斗层需要提供类幸存者游戏最直接的即时体验：移动、生存、自动攻击、构筑成长，以及随着能力形成后产生的压制感与爽感。

这种力量幻想本身不是需要回避的内容。它与世界观中对英雄主义的反思形成张力：玩家应当真实体验“变强”和“成为解决问题的人”的诱惑，之后才有可能理解这种路径的边界和代价。

### 2.2 战斗之外的局势判断

探索层不是进入下一场战斗的菜单，也不是低价值赶路。

玩家面对的是一个抽象化的行动结构。每一次有意义的行动都应至少改变信息、资源、风险、结构、状态或叙事中的一项。玩家可以不知道完整答案，但应逐渐学会判断自己面对的风险类型、可能收益和局势变化。

### 2.3 深入与止损

游戏不应默认“把所有内容清完”总是正确答案。

随着行动推进，风险、成本或局势压力应发生变化，使继续深入、转向和撤离都可能成为合理策略。放弃可选收益、保存已有成果或提前结束探索，应当存在成为正确决策的空间。

### 2.4 结构与战斗双向影响

结构层与局部战斗必须属于同一个因果循环：

- 玩家在结构层的判断改变后续战斗条件；
- 战斗中的资源消耗、成功、失败或其他重要结果改变之后的结构状态；
- 玩家能够逐渐理解并利用这种关系，而不是遭遇不可读的随机惩罚。

如果两层可以互相替换或删除而几乎不改变另一层，它们就还没有形成真正的核心循环。

## 3. 概念级核心循环

当前已确认的循环只定义因果方向，不提前决定具体系统实现：

```text
获得有限局势信息
        ↓
判断路线、收益与风险
        ↓
选择行动 / 继续深入 / 转向 / 撤离
        ↓
消耗资源并推进局势
        ↓
触发局部战斗或其他重要事件
        ↓
战斗与事件产生结果
        ↓
结果回流到结构空间
        ↓
重新判断当前局势
```

类幸存者战斗不是这个循环之外的独立小游戏；抽象探索也不是战斗之间的包装界面。

## 4. 抽象结构探索的角色

结构空间用于压缩复杂空间、事件、风险、资源和叙事，使玩家可以在较低内容制作成本下进行高密度判断。

设计优先级是 **单位节点/行动的信息与因果密度高于地图规模**。结构可以采用节点、网格、拓扑或其他表达形式；具体表现形式不是 Game Concept 层必须固定的内容。

结构层至少需要支持以下体验目标：

- 玩家知道自己当前处于什么局势；
- 玩家能看到至少一部分可行动方向；
- 未知信息足以产生判断，而不是纯猜测；
- 行动会留下后果；
- 已经重复、已知或低价值的过程可以被压缩；
- 局部挑战与结构选择之间存在可感知的因果关系。

## 5. 世界与玩法的关系

世界观不只是剧情背景。魔素、圣光、魔法制度、阶级与宗教秩序，应最终能够为玩家正在管理的风险、资源、力量和选择提供世界内解释。

当前已确认的世界基础包括：

- 魔素是一种会侵害生命、但同时可以被使用和转化的危险自然资源；
- 所谓圣光并非与魔素完全不同的超自然物质，而是被教会及相关阶层制度化、结构化的魔素处理体系；
- 暗魔法是未经教会体系加工和垄断的魔素使用方式，并不天然等于邪恶；
- 使用魔法与排出/消耗体内魔素有关，因此力量、健康、寿命和社会资源彼此关联；
- 教会建立的秩序具有真实的历史有效性，但其技术、解释权和资源垄断正在逐渐成为新的社会矛盾；
- 人类与魔族具有共同来源，教会对“魔族”与“魔物”的混淆具有政治功能；
- 当前时代处在旧秩序仍能运行、但生产关系与新的生产力逐渐发生冲突的阶段。

这些内容目前属于世界设计事实。它们具体如何进入战斗、探索、构筑和长期进程，需要在后续具体系统设计中决定。

## 6. 叙事与玩家力量的核心张力

游戏存在一个需要主动利用的矛盾：

**玩法给予玩家不断变强、清理敌人、解决危机的英雄能力；叙事则质疑“只要出现一个足够强的英雄，结构性问题就会得到解决”的想象。**

因此设计目标不是让玩家无法成为英雄，也不是通过文本否定玩家在玩法中获得的力量，而是让力量真实有效，同时让它不能自动解决所有问题。

玩家可以通过个人战斗能力处理具体危险，但世界中的生产、制度、阶级、战争与认知问题是否能够被同一种方式解决，目前仍是需要进一步设计的核心主题。

## 7. 当前不在 Game Concept 层决定的内容

以下内容不能因为当前代码已经存在就自动成为长期设计结论：

- 探索结构是否永久采用树状地图；
- 具体节点种类与数量；
- Sync 是否是最终战斗资源及其最终规则；
- 当前武器、被动、奖励和宝箱规则；
- 单局时长、地图规模和具体数值；
- Meta Progression 的形式；
- 具体剧情章节、NPC、派系任务和结局结构；
- 当前原型中的某个场景或脚本边界。

这些内容只有在后续 Design 中被明确选择后，才会成为设计权威，并进一步被 Requirement 抽取为某个版本的开发范围。

## 8. 待讨论问题

下面的问题决定 Game Concept 是否真正成立，应优先于具体系统细节讨论。

### 8.1 玩家最核心的幻想是什么？

目前存在至少两层：

- 类幸存者战斗中的“从弱到强、构筑成型、压制敌群”；
- 异世界勇者叙事中的“终于成为被世界需要的人”。

需要确认哪一层是主要入口，以及玩家最终希望经历怎样的变化。

### 8.2 30 秒核心体验是什么？

需要确认玩家在最短尺度上主要持续做什么，以及这件事本身为什么有趣。类幸存者战斗中的移动、走位和自动攻击很可能是主体，但目前不把现有实现直接视为最终答案。

### 8.3 5 分钟循环由什么驱动？

需要决定一次短周期中，探索选择、战斗、奖励、构筑和风险如何组成“再推进一点”的动力。

### 8.4 一次 Run 是什么？

需要定义自然的起点、推进阶段、Boss/目标、撤离、失败与结算，以及玩家为什么会开始下一局。

### 8.5 长期进程是什么？

需要决定长期增长主要来自：

- 数值力量；
- 新构筑选项；
- 对世界/系统的知识；
- 剧情和社会关系；
- 世界状态变化；
- 或它们的某种组合。

### 8.6 结构层真正管理的核心风险是什么？

“风险递增”已经是设计原则，但本项目尚未决定风险主要通过什么表现。时间、污染、资源、敌对压力、撤离难度等都只是候选，不在本文件中提前选定。

### 8.7 结构如何具体改变战斗，战斗又如何具体改变结构？

双向影响已经确定为核心原则，但实际传递哪些状态、资源和条件仍未决定。这将是后续系统设计的关键接口。

### 8.8 世界观如何进入玩家可操作系统？

需要确定魔素、圣光、污染、教会技术垄断等概念，哪些只是叙事背景，哪些真正成为玩家可以观察、使用、承担和改变的玩法变量。

### 8.9 英雄主义反思如何通过玩法发生？

需要避免出现“玩法持续奖励救世主式无双，剧情文字单独告诉玩家个人英雄主义有问题”的割裂。应决定玩家通过哪些具体后果、选择或系统关系亲自体验这一矛盾。

## 9. 当前讨论目标

在进入具体 System Design 前，Game Concept 至少需要收敛以下内容：

1. 一句话游戏定位；
2. 核心玩家幻想及其变化；
3. 30 秒、5 分钟、单局与长期循环；
4. 3–5 个 Game Pillars；
5. 关键 Anti-pillars；
6. 探索与战斗为什么必须同时存在；
7. 世界观如何服务核心玩法；
8. 这款游戏最需要通过原型验证的核心假设。
