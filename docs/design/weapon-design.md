# 武器设计

> 状态：active Game Design。
>
> 本文记录本项目类幸存者局部玩法中的正式武器设计规则。外部活动原始数据保存在 `docs/reference/`，只有明确选入本项目的规则才进入本文。

## 1. 武器层级

当前区分：

- **角色核心武器**：角色固有，不占普通武器升级槽，随角色等级与核心武器熟练度成长；
- **普通构筑武器**：在一次 Run 中获取、升级并参与随机武器构筑；
- **传说 / 超武形态**：满足武器等级与对应被动条件后，由普通构筑武器进化。

角色核心武器的规则见 `docs/design/character-design.md`。

## 2. 召唤武器

### 2.1 基础规则

本项目中的 **召唤武器** 不是短时间出现后消失的临时召唤技能。

只要该召唤武器当前属于玩家构筑，它就是一个 **常驻武器单位**：

- 在战斗中持续存在；
- 拥有自己的攻击行为；
- 拥有自己的 **速度**；
- 按自己的速度决定基础攻击间隔；
- 到达攻击时机后执行该召唤武器定义的攻击；
- 不需要依赖角色本体攻击事件才能行动。

概念上：

```text
获得召唤武器
    ↓
召唤武器常驻
    ↓
按照自身速度等待下一次攻击
    ↓
执行自己的索敌 / 发射 / 攻击逻辑
    ↓
继续等待下一次攻击
```

召唤武器的速度与角色速度 **完全独立**。

```text
基础召唤攻击间隔
= 该武器基准攻击间隔
× 100 / 召唤物自身速度
```

角色速度不会叠加到召唤物。

召唤体系可以通过 **召唤物速度增幅** 形成独立乘区：

```text
有效召唤物速度
= 召唤物自身速度
× 召唤物速度增幅
```

原活动中类似“召唤物速度 +30”的效果仍属于召唤物自身速度的平铺增加；召唤物速度增幅则是本项目额外的百分比 / 倍率型成长轴。

通用武器冷却降低是否影响某个召唤武器，由该武器自身声明，不默认强制。

### 2.2 人人为我

本项目采用基础版《银河球棒侠传说》的核心行为并改造成实时类幸存者武器：

- **人人为我**是常驻召唤武器；
- 按自己的速度周期性攻击；
- 每次攻击发射对应等级数量的 **火焰弹**；
- 火焰弹只从当前 **攻击范围内** 的敌人中随机选择目标；
- 每枚火焰弹独立随机瞄准一个有效目标；
- 发射数量、伤害倍率与自身速度优先沿用基础版等级数据作为设计基准。

其基础循环：

```text
人人为我常驻
    ↓
自身攻击计时完成
    ↓
取得攻击范围内敌人
    ↓
按当前等级生成 N 枚火焰弹
    ↓
每枚火焰弹随机选择范围内有效目标
    ↓
投射物飞向目标并造成火属性伤害
```

当前仍不固定：

- 默认攻击范围；
- 默认投射物飞行速度；
- 一轮多枚火焰弹的具体发射间隔；
- 多枚火焰弹能否重复选择同一个目标；
- 没有范围内敌人时的处理细节；
- 火焰弹的削韧值。

这些数据应在正式平衡或 playable validation 时确定，而不是为了补齐字段提前猜测。

## 3. 类幸存者专属武器属性

属性的统一定义见 `docs/design/attributes.md`。

武器设计这里只说明它们在武器中的具体消费方式。

当前增加：

### 3.1 投射物飞行速度倍率

**投射物飞行速度倍率**用于缩短或延长投射物从生成到到达目标 / 终点的时间。

它只影响声明为可受投射物速度影响的攻击。

例如：

- 火焰弹；
- 箭矢；
- 飞剑；
- 其他具有实际飞行过程的弹体。

它不应默认改变：

- 武器攻击频率；
- 瞬时射线；
- 角色移动速度；
- 不存在飞行过程的范围攻击。

### 3.2 攻击范围倍率

将原先较宽泛的“范围倍率”统一明确为 **攻击范围倍率**。

攻击范围倍率用于扩大声明为可受范围影响的武器空间参数，例如：

- 索敌最大距离；
- 近战攻击距离；
- 范围攻击半径；
- 召唤武器能够选择目标的有效范围；
- 其他明确属于武器攻击范围的尺寸。

具体武器可以声明哪些空间参数受攻击范围倍率影响；不要求所有视觉尺寸、击退距离或投射物生命周期都自动随之缩放。

## 4. 与被动构筑的关系

**投射物飞行速度倍率**与**攻击范围倍率**都是正式的类幸存者构筑属性，因此可以由合适的被动、角色成长、事件或其他构筑来源提供。

当前只确认：

- 它们可以作为被动效果的候选属性；
- 是否附加到某一个具体被动，需要结合该被动原本的构筑定位判断；
- 不为了覆盖属性表而强行让每项属性都有一个专属被动。

武器相关的几个速度 / 空间属性职责如下：

```text
角色速度
→ 非召唤武器的基础攻击频率

武器冷却降低
→ 进一步缩短适用武器的攻击间隔

召唤物自身速度
→ 召唤武器自己的基础攻击频率

召唤物速度增幅
→ 专门放大召唤物自身速度

投射物飞行速度倍率
→ 发出的弹体飞得多快

攻击范围倍率
→ 多远 / 多大的空间可以被该攻击覆盖
```

各自保持独立，避免一个属性同时承担多个实时战斗职责。
