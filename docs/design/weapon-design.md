# 武器设计

> 状态：active Game Design。
>
> 本文记录本项目类幸存者局部玩法中的正式武器设计规则。外部活动原始数据保存在 `docs/reference/`，只有明确选入本项目的规则才进入本文。

## 1. 武器层级

当前区分：

- **角色核心武器**：角色固有，不占普通武器升级槽，随角色等级与核心武器熟练度成长；
- **普通构筑武器**：在一次 Run 中获取、升级并参与随机武器构筑；
- **传说 / 超武形态**：满足武器等级与对应被动条件后，由普通构筑武器进化。

角色核心武器的规则见 `docs/design/character-design.md`。

## 2. 武器标签

### 2.1 标签是正式构筑规则

武器标签不只是展示文字，而是武器与被动 / 属性之间的显式连接点。

当前原则：

- 每把武器明确声明自己的标签；
- 被动或属性可以声明“只作用于某标签”；
- 没有对应标签的武器不受到该效果；
- 不维护类似《吸血鬼幸存者》那样隐藏在武器实现内部的兼容名单；
- 标签既方便玩家理解，也方便设计和后续数据配置。

概念上：

```text
武器标签
    ↓
被动 / 属性按标签筛选
    ↓
只有匹配标签的武器获得效果
```

目前已经确认的标签型规则：

```text
发射类武器攻击次数
→ 仅作用于「发射」标签

召唤物速度增幅
→ 仅作用于「召唤」标签
```

后续如果出现新的标签型构筑，再逐项加入；不提前建立无消费者的标签规则。

### 2.2 当前三把参考武器的标签

依据《银河球棒侠传说》基础版官方 Wiki 口径：

| 武器 | 标签 | 当前项目含义 |
|---|---|---|
| **彩虹球棒** | 随机、集中 | 随机属性、多段集中攻击；不属于发射或召唤 |
| **人人为我** | 召唤、发射 | 常驻召唤武器，同时发射投射物 |
| **游侠长弓** | 范围、发射 | 自动进行范围型发射攻击 |

标签来自源资料；具体实时行为由本项目重新解释。

## 3. 召唤武器

### 3.1 基础规则

本项目中的 **召唤武器** 不是短时间出现后消失的临时召唤技能。

只要该武器带有 **`召唤`** 标签并属于玩家当前构筑，它就是一个常驻武器单位：

- 在战斗中持续存在；
- 拥有自己的攻击行为；
- 拥有自己的 **召唤物自身速度**；
- 召唤物速度与角色速度完全独立；
- 按自己的速度决定基础攻击间隔；
- 不需要依赖角色本体攻击事件才能行动。

```text
基础召唤攻击间隔
= 该武器基准攻击间隔
× 100 / 召唤物自身速度
```

角色速度不会叠加到召唤物。

带有 `召唤` 标签的武器可以受到 **召唤物速度增幅**：

```text
有效召唤物速度
= 召唤物自身速度
× 召唤物速度增幅
```

原活动中类似“召唤物速度 +30”的效果属于召唤物自身速度的平铺增加；召唤物速度增幅是独立倍率乘区。

## 4. 当前武器

### 4.1 彩虹球棒

源标签：

- **随机**
- **集中**

当前项目保留其“追加 / 附加伤害”定位。

由于没有 `发射` 标签：

- 不受 **发射类武器攻击次数** 影响。

由于没有 `召唤` 标签：

- 不受 **召唤物速度增幅** 影响。

具体触发条件和实时攻击表现继续以已有彩虹球棒设计为准，不因为标签系统额外改写。

### 4.2 人人为我

源标签：

- **召唤**
- **发射**

当前项目改造：

- 常驻召唤武器；
- 按自己的召唤物速度周期性攻击；
- 每次攻击发射对应等级数量的火焰弹；
- 火焰弹只从攻击范围内的敌人中随机选择目标；
- 每枚火焰弹独立随机瞄准一个有效目标；
- 发射数量、伤害倍率与自身速度优先沿用基础版等级数据作为设计基准。

因为具有 `召唤` 标签：

- 受到 **召唤物速度增幅**；
- 角色速度不影响它。

因为同时具有 `发射` 标签：

```text
实际火焰弹数量
= 当前等级基础发射数量
+ 发射类武器攻击次数
```

基础循环：

```text
人人为我常驻
    ↓
按照自身速度等待
    ↓
取得攻击范围内敌人
    ↓
生成当前发射次数的火焰弹
    ↓
每枚随机选择合法目标
    ↓
投射物飞向目标并造成火属性伤害
```

当前仍不固定：

- 默认攻击范围；
- 默认投射物飞行速度；
- 一轮多枚火焰弹的具体发射间隔；
- 多枚火焰弹能否重复选择同一个目标；
- 没有范围内敌人时的处理细节；
- 火焰弹削韧值。

### 4.3 游侠长弓

源标签：

- **范围**
- **发射**

本项目不采用原活动的终结技触发方式，将其改造成 **自动攻击武器**。

当前行为：

- 按普通自动武器节奏周期性攻击；
- 使用角色速度决定基础攻击频率；
- 可以受到武器冷却降低影响；
- 每次攻击向攻击范围内的随机目标发射 **长矛**；
- 每一枚长矛独立随机选择合法目标；
- 允许多枚长矛选择同一个目标；
- 长矛拥有实际飞行过程，受到投射物飞行速度倍率影响；
- 当前等级提供基础发射数量；
- `发射` 标签使其受到发射类武器攻击次数影响。

```text
实际长矛数量
= 当前等级基础发射数量
+ 发射类武器攻击次数
```

基础循环：

```text
自动攻击计时完成
    ↓
取得攻击范围内敌人
    ↓
生成 N 枚长矛
    ↓
每枚长矛独立随机选择目标
    ↓
长矛飞向目标
    ↓
命中并造成伤害
```

`范围` 标签保留源武器身份；它是否进一步被某个“范围标签专属被动”强化，等实际出现对应被动时再设计。

当前仍不固定：

- 默认攻击间隔；
- 默认攻击范围；
- 长矛基础飞行速度；
- 是否保留源武器的命中范围溅射；
- 削韧值；
- 多枚长矛之间的发射间隔。

## 5. 类幸存者专属武器属性

属性统一定义见 `docs/design/attributes.md`。

当前武器可消费的主要属性包括：

- 武器冷却降低；
- 召唤物速度增幅；
- 效果持续时间增幅；
- 发射类武器攻击次数；
- 投射物飞行速度倍率；
- 攻击范围倍率。

其中已经采用标签门控的属性：

| 属性 | 生效条件 |
|---|---|
| 召唤物速度增幅 | 武器具有 `召唤` 标签 |
| 发射类武器攻击次数 | 武器具有 `发射` 标签 |

其他属性是否进一步通过标签限制，等具体构筑出现时再决定。

## 6. 标签设计原则

### 6.1 标签显式而非隐藏

如果一个被动写着：

> 发射类武器攻击次数 +2

玩家只需查看武器是否存在 `发射` 标签，就能判断是否生效。

不应出现：

> 武器看起来像投射物，但实际上因为隐藏兼容表而不吃该效果。

### 6.2 标签描述玩法职责，不描述实现细节

标签应表达玩家可以理解的武器类别，例如：

- 召唤；
- 发射；
- 范围；
- 集中；
- 随机。

不要因为两个武器代码上都使用 Projectile 节点，就自动赋予相同玩法标签。

### 6.3 标签可以重叠

例如人人为我同时是：

```text
召唤
+
发射
```

因此它可以同时参与：

- 召唤构筑；
- 发射构筑。

这种交叉正是标签系统的主要构筑价值。
