# 共鸣配饰设计

> 状态：active Game Design。
>
> 本文是《银河球棒侠传说》基础版 **13 个武器共鸣配饰**在本项目中的统一正式入口。
>
> 原活动数值与来源仍保存在各武器的 `docs/reference/weapons/galactic-baseballer/` 文件中；这里记录本项目采用的构筑语义。独立被动配饰见 `docs/design/passive-accessories.md`。

## 1. 统一原则

- 共鸣配饰既是对应武器的传说 / 超武进化条件，也可以独立参与构筑；
- 标签型强化按显式武器标签生效，不维护隐藏兼容表；
- 属性型强化直接进入 `docs/design/attributes.md` 对应属性；
- 若对应武器本身延期，其共鸣配饰也一起延期，不为单个配饰提前建立系统；
- 源版数值除已明确做实时化改造的项目外，默认保持原数值。

## 2. 当前映射

| 对应武器 | 共鸣配饰 | Lv1 → Lv4 | 本项目规则 |
|---|---|---|---|
| 彩虹球棒 | **迪斯科棒球** | 每种已出现伤害属性 +4% / +5% / +6% / +7% 伤害 | 保留多属性构筑语义；按本局已实际出现的不同伤害属性种类提供角色 / 武器全局增伤 |
| 人人为我 | **我为人人** | 召唤类武器速度 +30 / +40 / +50 / +60 | 只作用于 `召唤` 标签；平铺增加召唤物自身速度，不提高角色速度 |
| 游侠长弓 | **裂风箭矢** | +2 / +3 / +4 / +5 | 直接提供 **发射类武器攻击次数**；只作用于 `发射` 标签 |
| 雷电荆棘 | **冠冕碎晶** | 角色速度 +30 / +40 / +50 / +60 | 直接提高角色速度；不提高召唤物自身速度 |

| 寒冰飞剑 | **冰火令符** | 冰 / 火伤害 +30% / +40% / +50% / +60% | 提供冰、火属性伤害提高 |
| 幸运轮盘 | **孤注一掷** | 虚数 / 量子 / 物理伤害 +30% / +40% / +50% / +60% | 提供虚数、量子、物理属性伤害提高 |

## 3. 与属性体系的关系

这些配饰已经为下列属性 / 构筑轴提供明确消费者：

- 角色速度；
- 召唤物自身速度；
- 发射类武器攻击次数；
- 攻击范围倍率 / `范围` 标签专属范围强化；
- 敌人效果抵抗降低；
- 七属性伤害提高；
- 标签对精英 / Boss 增伤；
- 多属性种类计数型全局增伤；
- 攻击行为计数型下一击强化。

其中七属性伤害提高目前仍属于 **Game Design 已确认、实现 Scope 未选择**。当这些共鸣配饰进入 Requirement 时，应同步把对应属性纳入实现 Scope，而不是另造配饰专用伤害字段。

## 4. 延期项

当前只有两组共鸣配饰随武器一起延期：

- 纯美的祝祷 + 黄金玫瑰；
- 筑城之志 + 永恒之心。

它们的源版数据继续保留，但不进入当前实时玩法 Requirement。
