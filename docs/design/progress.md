## 本 PR 已新增

- 属性体系已独立收敛到 `docs/design/attributes.md`；
- 角色设计只保留角色如何使用 / 成长属性，不再重复维护属性定义；
- 武器设计引用统一属性定义，并保留具体武器如何消费攻击范围倍率、投射物飞行速度倍率等说明。

- 召唤物速度与角色速度完全独立，并新增召唤物速度增幅乘区；
- 新增武器冷却降低，作为速度之外的独立冷却乘区；
- “移动速度加成”统一命名为“移动速度增幅”；
- 玩家常规不承受概率型控制 / 负面效果，因此不建立效果抵抗；
- 战技点基础上限固定为 5，并纳入回能体系；角色天赋可提高上限，技能可额外回复。

- 对照《吸血鬼幸存者》完成属性查漏补缺：新增同步值恢复效率、效果持续时间增幅、额外攻击数量；
- Luck、Curse、Revival 暂不机械照搬；Reroll / Skip / Banish / Seal 归为构筑选择控制而非战斗属性。

- 标签成为正式构筑选择器：不再依赖隐藏兼容表；
- `发射` 标签统一接收“发射类武器攻击次数”；
- `召唤` 标签统一接收“召唤物速度增幅”；
- 已补齐彩虹球棒、人人为我、游侠长弓三把武器的官方基础版标签；
- 游侠长弓确定为自动攻击武器，向攻击范围内随机目标发射长矛。

- 已整理下一把武器“雷电荆棘”：标签为 `发射`，对应配饰“冠冕碎晶”，传说武器“惊雷冠冕”；源机制为附着、周期持续伤害、弹射、死亡转移，超武增加持续伤害引爆。

- 雷电荆棘确定为持续锁定型发射武器：按角色速度周期放电，紫色闪电连接标记目标并继续弹射；
- 标记目标死亡后自动转移到距离玩家最近的下一个敌人；
- 发射类武器攻击次数只增加雷电荆棘弹射次数；
- 惊雷冠冕视觉确定为绿色 + 紫色闪电。

- 雷电荆棘首次标记自动选择距离玩家最近敌人，弹射按最近邻链传播；
- 雷电荆棘主目标削韧 20、弹射目标削韧 10；额外天赋 / Buff 可再提供削韧倍率修正；
- 惊雷冠冕保留持续伤害引爆；当前可引爆的 DoT 来源仅为击破持续伤害 / 击破异常。

- 普通自动武器采用统一速度换算：100 速度 = 1.0 秒一次，速度越小攻击越慢；
- 游侠长弓基础速度 100；雷电荆棘基础速度 80；两者都受到玩家速度与武器冷却降低影响；
- 雷电荆棘首次 / 重建标记只在玩家攻击范围内选择最近敌人；无敌人时不保持标记；
- 雷电荆棘主闪电最大视觉连接长度 = 玩家攻击范围；
- 雷电荆棘每次弹射以最后受击敌人为中心，弹射半径 = 玩家攻击范围的 50%，从范围内其他敌人随机选择并允许回跳；
- 无其他可弹射目标时，在当前敌人自身重复一次弹射伤害并消耗 1 次弹射次数。

- 疾风巨锤正式采用 `召唤、集中`：沿用召唤速度 120 → 180 → 240，只在玩家攻击范围内锁定最高生命目标；
- 震荡改造为唯一圆形区域：半径暂定 3 unit（1 unit ≈ 1 个玩家身位；球棒基础攻击距离 2 unit），区域内其他敌人受伤时向震荡目标传导 10% 伤害；震荡不转移；
- 疾风巨锤主攻击削韧 20，震荡传导伤害不削韧；
- 震荡只传导其他敌人的实际生命值损失：暴击、DoT、击破伤害先完成结算，再按实际掉血的 10% 对震荡目标造成风属性伤害，过量伤害不计入；
- 传说形态中文名确定为“碎牢重锤”；每击沿用官方 10000% 倍率，保留 50% 固定概率继续攻击、最多 4 连击；
- 碎牢重锤只攻击锁定的最高生命目标，不造成小范围伤害；下一击在上一击命中帧时开始播放，使连击动画连续衔接。

- 已整理下一把武器“甜美的沉眠”：量子属性、`范围` 标签，击杀敌人后以被击败目标的最大生命值比例 + 基础伤害造成范围爆炸；
- 甜美的沉眠 Lv1–Lv8 从 60% 最大生命值 + 300% 基础伤害成长至 120% + 1500%；
- 共鸣配饰“硝烟飘带”在本项目改为 `范围` 标签专属攻击范围增幅：Lv1–Lv4 分别 +6% / +8% / +10% / +12%，不再按额外命中目标数增伤；
- 甜美的沉眠普通尸爆基础半径 2 unit，每个命中目标削韧 10；
- 传说形态中文名确定为“盒中惊喜”：保留量子 + 虚数、200% 被击败目标最大生命值 + 3000% 基础伤害，但由源活动全体攻击改为死亡位置中心的基础 4 unit 大范围爆炸。

- 甜美的沉眠允许自触发尸爆连锁：原条件为“我方角色或武器消灭敌方目标”，甜美的沉眠本身属于武器，因此其爆炸击杀同样会再次触发，在新的死亡位置继续尸爆。

- 甜美的沉眠最大生命值比例伤害对精英 / Boss 完整生效，不做额外削减或封顶；击杀 Boss 后可利用其高最大生命值尸爆重创甚至击杀附近其他 Boss，并继续形成 Boss 尸爆链，作为高收益高风险机制；
- 盒中惊喜削韧固定为 10，与普通甜美的沉眠一致。

- 已整理下一把武器“寒冰飞剑”：冰属性、`发射` 标签，源机制为我方角色连续行动达到 3 次后触发多枚飞剑，每额外连续行动再增加飞剑数量；
- 寒冰飞剑 Lv1–Lv8 基础发射数量 3 → 5 → 7，单枚伤害 300% → 1200%；
- 共鸣配饰“冰火令符”提供冰 / 火属性伤害 +30% / +40% / +50% / +60%；
- 传说形态中文名确定为“炽焰大剑”：冰 + 火、`发射`，基础 7 剑 × 1500%，每额外充能 +2 剑，并对精英 / Boss +30%。

- 寒冰飞剑实时版由角色核心武器命中的敌人数充能：同一次攻击中每个实际命中的敌人计 1 点，同一敌人同一次攻击只计一次；累计至少 3 点触发；
- 触发时消耗全部充能；普通形态实际飞剑数 = 当前等级基础数量 + max(充能-3,0) + 发射类武器攻击次数；
- 炽焰大剑实际飞剑数 = 7 + max(充能-3,0)×2 + 发射类武器攻击次数；
- 飞剑连续爆发式发射，每枚只命中单一目标，本项目因此补充 `集中` 标签；每枚发射时优先锁定最近敌人，当前目标死亡后后续飞剑重新索敌；
- 普通冰剑命中冰弱点时削韧 5；炽焰大剑每枚随机火 / 冰属性，对对应弱点命中时削韧 5；
- 寒冰飞剑由角色自身武器构筑驱动，区别于游侠长弓主要依赖普通武器自身的速度 / 冷却 / 发射次数构筑。

- 所有削韧统一要求弱点匹配：攻击属性与敌人弱点匹配时才按武器 / 攻击声明的基础削韧值扣减韧性；不匹配弱点时仍正常造成生命值伤害，但不削韧。此前记录的 5 / 10 / 20 等削韧值均按此全局规则解释。

- 已整理下一把武器“幸运轮盘”：虚数属性、`召唤、发射` 标签，源机制为按独立速度行动并连续发射筹码，每枚筹码随机获得 1–6 点，最后按累计点数结算伤害；
- 幸运轮盘 Lv1–Lv8：速度 90 → 130，发射次数 4 → 5 → 7，每点伤害倍率 100% → 600%；
- 共鸣配饰“孤注一掷”提供虚数 / 量子 / 物理属性伤害 +30% / +40% / +50% / +60%；
- 传说形态英文名 Gambit in the Game：虚数 + 量子、`召唤、发射`、速度 150、固定 9 枚筹码；掷出 6 时该筹码改为 36 点，每点造成 666% 基础伤害；正式中文名待官方口径回填。
