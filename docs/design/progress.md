# 当前设计进度

> 用途：记录当前进行中的 Game Design 工作范围，便于通过本 PR 查看阶段性进展。
>
> 本文件不替代各主题设计文档；已确认规则仍写入对应的 `docs/design/` 文档，外部原始资料仍写入 `docs/reference/`。

## 当前工作主题

- 类幸存者武器设计
- 《银河球棒侠传说》基础版武器资料整理与实时玩法改造
- 召唤武器、投射物、追加攻击等武器行为类型
- 生命值 + 韧性值双条敌人方向
- 破韧、击破异常与武器构筑关系
- 类幸存者专属属性与被动的对应关系

## 已进入 main 的基线

- 多角色选择进入模拟宇宙测试；
- 开拓者 / 小浣熊作为首个角色；
- 角色核心武器“球棒”；
- 同步值取代玩家传统生命值；
- 速度、攻击力、防御力、暴击、效果命中、击破特攻、回能效率等角色/构筑属性；
- 移动速度、攻击范围倍率、投射物飞行速度倍率、拾取范围、经验/资源获取倍率等实时玩法属性；
- 召唤武器为常驻、按自身速度独立行动的武器单位；
- 彩虹球棒与人人为我基础版参考资料。

## 本 PR 已新增

- 属性体系已独立收敛到 `docs/design/attributes.md`；
- 角色设计只保留角色如何使用 / 成长属性，不再重复维护属性定义；
- 武器设计引用统一属性定义，并保留具体武器如何消费攻击范围倍率、投射物飞行速度倍率等说明。

- 召唤物速度与角色速度完全独立，并新增召唤物速度增幅乘区；
- 新增武器冷却降低，作为速度之外的独立冷却乘区；
- “移动速度加成”统一命名为“移动速度增幅”；
- 玩家常规不承受概率型控制 / 负面效果，因此不建立效果抵抗；
- 战技点基础上限固定为 5，并纳入回能体系；角色天赋可提高上限，技能可额外回复。

- 对照《吸血鬼幸存者》完成属性查漏补缺：新增同步值恢复效率、效果持续时间增幅、额外攻击数量；
- Luck、Curse、Revival 暂不机械照搬；Reroll / Skip / Banish / Seal 归为构筑选择控制而非战斗属性。

- 标签成为正式构筑选择器：不再依赖隐藏兼容表；
- `发射` 标签统一接收“发射类武器攻击次数”；
- `召唤` 标签统一接收“召唤物速度增幅”；
- 已补齐彩虹球棒、人人为我、游侠长弓三把武器的官方基础版标签；
- 游侠长弓确定为自动攻击武器，向攻击范围内随机目标发射长矛。

- 已整理下一把武器“雷电荆棘”：标签为 `发射`，对应配饰“冠冕碎晶”，传说武器“惊雷冠冕”；源机制为附着、周期持续伤害、弹射、死亡转移，超武增加持续伤害引爆。

- 雷电荆棘确定为持续锁定型发射武器：按角色速度周期放电，紫色闪电连接标记目标并继续弹射；
- 标记目标死亡后自动转移到距离玩家最近的下一个敌人；
- 发射类武器攻击次数只增加雷电荆棘弹射次数；
- 惊雷冠冕视觉确定为绿色 + 紫色闪电。
