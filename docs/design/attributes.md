# 属性体系

> 状态：active Game Design。
>
> 本文是当前项目 **角色 / 构筑属性的统一定义入口**。
>
> 它回答三个问题：
>
> 1. 这个属性是什么；
> 2. 它在游戏里具体解决什么问题；
> 3. 哪些数值是角色/构筑属性，哪些只是武器参数、敌人资源或战斗状态。
>
> 具体数值曲线、上限、装备词条和被动分配，在对应玩法进入 Requirement 后再决定。

## 1. 属性体系的用途

本项目不是直接复制《崩坏：星穹铁道》的角色面板，而是保留玩家熟悉的属性语言，再补充实时类幸存者需要的空间与成长属性。

属性体系承担四类职责：

```text
角色基础差异
    ↓
不同角色有不同战斗底盘

局内构筑
    ↓
被动 / 武器 / 事件改变属性

实时战斗表现
    ↓
攻击频率、移动、范围、弹速等产生直接体感

星铁机制映射
    ↓
效果命中、削韧、击破、回能等保留原作辨识度
```

原则：

- 一个属性只承担一个清晰职责；
- 不为了面板完整而提前增加没有消费者的属性；
- 同一含义不重复建立多个属性；
- 原作属性可以改造，但不能仅因为原作存在就照搬。

---

## 2. 当前正式角色 / 构筑属性

### 2.1 同步值上限

**用途：玩家核心生存资源容量。**

本项目玩家不使用传统生命值作为主要生存条，改用 **同步值**。

同步值上限决定：

- 玩家能够承受多少同步损伤；
- 防御、生存类构筑的基础容量；
- 不同角色在生存能力上的基础差异。

它不等于敌人的生命值。

当前只确定同步值承担传统 HP 的核心生存职责，具体归零后果、恢复规则和层间继承仍由后续设计决定。

---

### 2.2 攻击力

**用途：通用基础输出能力。**

攻击力参与适用的：

- 角色核心武器伤害；
- 普通构筑武器伤害；
- 战技 / 终结技伤害；
- 其他明确声明受攻击力影响的效果。

攻击力提供一个共享的伤害成长轴，使角色等级、被动与不同武器可以围绕同一个基础输出属性产生协同。

具体伤害公式暂不固定。

---

### 2.3 防御力

**用途：降低玩家受到的同步损伤。**

防御力是玩家侧主要的基础减伤属性。

其职责是：

- 让不同角色拥有不同的基础抗压能力；
- 为防御型被动和角色成长提供明确消费者；
- 在“主动走位”之外提供有限的生存成长空间。

本项目不建立传统 HP + DEF 双体系；防御力服务于同步值。

具体减伤公式、是否存在收益递减和防御穿透以后再定。

---

### 2.4 速度

**用途：决定攻击行为多久执行一次。**

速度是当前项目统一的 **攻击频率属性**。

参考《崩坏：星穹铁道》的行动值反比关系，本项目采用：

```text
攻击间隔倍率 = 100 / 速度

实际攻击间隔
= 武器 / 技能基准攻击间隔
× 100 / 速度
```

例如一个基准攻击间隔为 1 秒的攻击：

| 速度 | 实际攻击间隔 |
|---:|---:|
| 100 | 1.000 秒 |
| 125 | 0.800 秒 |
| 150 | 0.667 秒 |
| 200 | 0.500 秒 |

速度可以作用于：

- 角色核心武器；
- 普通自动武器；
- 其他明确使用角色速度的周期性攻击。

速度 **不等于移动速度**，也不自动改变投射物飞行速度。

**召唤武器不使用角色速度。** 召唤物拥有完全独立的自身速度，并由召唤物自己的速度决定攻击间隔。

---

### 2.5 暴击率

**用途：决定适用伤害是否发生暴击。**

暴击率为输出构筑提供概率型成长轴。

它适用于哪些伤害，需要由对应武器 / 技能声明。

例如未来可以存在：

- 普通直接伤害可暴击；
- 某些持续伤害不可暴击；
- 某些特殊武器拥有独立暴击规则。

当前不提前统一所有伤害类型的暴击资格。

---

### 2.6 暴击伤害

**用途：提高暴击发生时的伤害收益。**

暴击伤害与暴击率构成一组互相依赖的构筑属性：

```text
暴击率
→ 暴击出现得更频繁

暴击伤害
→ 每次暴击收益更高
```

具体基础暴击倍率与成长上限以后再定。

---

### 2.7 效果命中

**用途：提高概率型负面效果的施加成功率。**

当前计划中的敌方负面效果包括但不限于：

- 防御力降低；
- 虚弱；
- 灼烧；
- 风化；
- 触电；
- 裂伤；
- 其他武器 / 角色专属负面效果。

如果一个效果拥有“基础施加概率”，则可以受效果命中影响。

效果命中解决的是：

> **负面效果能不能成功挂上。**

它不直接决定：

- 负面效果伤害；
- 持续时间；
- 层数上限；
- 击破伤害。

这些由对应效果自己的规则决定。

当前玩家侧 **不设置效果抵抗属性**。

常规战斗中，玩家不会被施加需要概率判定的控制类 / 负面效果；玩家主要通过走位与回避处理威胁。只有明确设计为特殊机制的内容可以例外处理，因此没有必要建立一条常规“效果抵抗”构筑轴。

---

### 2.8 击破特攻

**用途：强化敌人被击破之后产生的收益。**

敌人采用：

```text
红条：生命值
白条：韧性值
```

攻击可以同时造成生命值伤害和削韧。

韧性值归零后，敌人进入击破状态并产生对应属性的击破异常。

击破特攻用于强化：

- 击破伤害；
- 对应属性击破异常的适用收益；
- 未来明确设计为受击破特攻影响的效果。

它不决定一击削多少韧。

**削韧值属于武器 / 攻击本身的参数，不是角色基础属性。**

因此：

```text
削韧值
→ 多快把白条打空

击破特攻
→ 白条打空以后收益有多大
```

---

### 2.9 回能效率

**用途：提高战斗资源的恢复效率。**

角色拥有：

- 战技；
- 战技点；
- 终结技；
- 终结技能量。

回能效率用于提高符合条件的：

- 战技点恢复；
- 终结技能量恢复。

战技点基础上限为 **5 点**。部分角色天赋可以提高该上限，部分技能可以额外恢复战技点。

击杀敌人是计划中的回能来源之一，因此回能效率会影响击杀带来的战斗资源恢复。

当前不固定：

- 每次击杀的基础回能；
- 普通 / 精英 / Boss 的回能差异；
- 战技点与终结技能量是否使用完全相同的倍率；
- 其他常规回能来源。

## 3. 类幸存者专属属性

这些属性主要解决回合制原作中不存在的 **实时空间战斗问题**。

### 3.1 移动速度

**用途：决定玩家角色在战场中的实际移动能力。**

它直接影响：

- 躲避敌人；
- 拉扯敌群；
- 接近或远离目标；
- 拾取经验和资源的效率；
- 在破韧前后重新建立安全距离。

速度与移动速度存在弱关联：

- 基础速度更高的角色，体感上可以略快；
- 但速度对实际移动速度的影响应边际递减；
- **移动速度增幅才是实战走位的主要成长轴。**

具体关联函数暂不固定。

---

### 3.2 武器冷却降低

**用途：在速度之外，进一步缩短适用武器的攻击间隔。**

速度负责基础攻击频率；武器冷却降低作为独立乘区，与速度共同决定最终攻击间隔。

普通使用角色速度的武器：

```text
实际攻击间隔
= 武器基准攻击间隔
× 100 / 角色速度
× (1 - 武器冷却降低)
```

例如：

- 角色速度决定基础攻击节奏；
- 武器冷却降低再对这个结果进行乘算压缩。

因此两者职责不同：

```text
速度
→ 基础攻击频率

武器冷却降低
→ 在现有攻击频率上进一步缩短冷却
```

具体上限、是否存在硬下限以及特殊武器是否免疫该属性，后续平衡时再决定。

---

### 3.3 召唤物速度增幅

**用途：专门提高常驻召唤武器的行动频率。**

召唤物速度与角色速度完全独立。

召唤武器的基础攻击节奏由自己的速度决定：

```text
召唤武器基础间隔
= 召唤武器基准攻击间隔
× 100 / 召唤物自身速度
```

**召唤物速度增幅**作为召唤体系专属乘区，提高召唤物自身速度的实际效果，而不会提高角色本体速度。

概念上：

```text
有效召唤物速度
= 召唤物自身速度
× 召唤物速度增幅
```

来源中若存在“召唤物速度 +X”这类平铺数值，仍先作用到召唤物自身速度；“召唤物速度增幅”是另一独立乘区。

是否让通用 **武器冷却降低** 同时影响召唤武器，由具体召唤武器声明；当前不强制所有召唤武器吃同一冷却乘区。

---

### 3.4 攻击范围倍率

**用途：放大适用武器的空间覆盖能力。**

它可以影响武器声明为可缩放的：

- 索敌距离；
- 近战攻击距离；
- 圆形 / 扇形 / 矩形攻击区域；
- 召唤武器选择目标的最大距离；
- 其他明确属于攻击覆盖范围的参数。

例如“人人为我”只会从自己的攻击范围内随机选择敌人，因此攻击范围倍率可以扩大其合法目标集合。

攻击范围倍率 **不默认影响**：

- 击退距离；
- 投射物飞行速度；
- 投射物持续时间；
- 纯视觉特效尺寸。

---

### 3.5 投射物飞行速度倍率

**用途：改变具有实际飞行过程的攻击移动速度。**

适用对象例如：

- 火焰弹；
- 箭矢；
- 飞剑；
- 其他实体弹体。

它影响：

- 投射物抵达目标需要的时间；
- 对移动目标的命中稳定性；
- 远距离武器的输出延迟；
- 弹幕的空间体感。

它不影响：

- 武器多久发射一次；
- 玩家移动速度；
- 瞬时射线；
- 没有实体飞行过程的范围攻击。

因此：

```text
速度
→ 发射频率

投射物飞行速度倍率
→ 发出去以后飞多快
```

---

### 3.6 拾取范围

**用途：扩大经验与可拾取资源的收集半径。**

它主要降低玩家为了捡取资源而反复折返的操作成本，并允许构筑对“战斗位置”和“资源收集”进行一定程度的解耦。

适用对象包括：

- 经验；
- 局内资源；
- 其他明确使用拾取范围的掉落物。

---

### 3.7 经验获取倍率

**用途：提高角色在当前成长体系中获得经验的效率。**

它解决的是：

> 同样击杀 / 获取经验源时，角色升级得有多快。

它主要服务于：

- 局内角色等级成长；
- 更早获得等级带来的基础属性提升；
- 加快一次 Run 中的成长节奏。

角色等级最终是纯局内、纯局外还是混合成长，目前仍未确定，因此该属性的具体作用边界以后再收敛。

---

### 3.8 资源获取倍率

**用途：提高适用局内资源的获得量。**

它可以服务于：

- 阵列探索资源；
- 战斗内货币 / 兑换资源；
- 其他明确声明受资源倍率影响的局内产出。

它不自动影响经验，因为经验已有独立的经验获取倍率。

具体哪些资源受该属性影响，由各资源系统自行声明。

---

## 4. 七属性伤害提高

当前设计层预留七项：

- 物理属性伤害提高；
- 火属性伤害提高；
- 冰属性伤害提高；
- 雷属性伤害提高；
- 风属性伤害提高；
- 量子属性伤害提高；
- 虚数属性伤害提高。

**用途：为未来属性专精、属性克制和对应角色 / 武器构筑预留稳定成长轴。**

它们可以用于：

```text
角色属性专精
武器属性专精
属性队伍 / 构筑
属性克制
对应击破体系
```

但当前版本 **暂不实现属性克制**。

因此这七项目前属于：

> **Game Design 已命名、实现 Scope 未选择。**

不要因为文档已经存在这些属性，就提前在当前实现里增加七套属性逻辑。

## 5. 不是角色属性，但与属性体系直接相关的战斗数值

为了避免面板无限膨胀，下列内容不作为通用角色属性。

### 5.1 削韧值

属于具体攻击 / 武器。

用途：

> 决定一次攻击削减多少敌人韧性值。

不同武器可以有完全不同的削韧能力。

---

### 5.2 敌人生命值

属于敌人资源。

用途：

> 生命值归零时敌人死亡。

敌人可以比传统类幸存者杂兵拥有更高生命值，以保证追加攻击、破韧和负面效果有发挥空间。

---

### 5.3 敌人韧性值

属于敌人资源。

用途：

> 形成击破前 / 击破后的战斗阶段。

当前方向：

- 韧性未破：敌人保持正常威胁；
- 韧性归零：敌人进入击破状态；
- 击破后移动速度和攻击速度下降；
- 同时受到对应属性的击破异常。

这使破韧承担一部分实时控场职责，而不是只有一次额外伤害。

---

### 5.4 战技点

属于角色战斗资源。

用途：

> 支付战技相关消耗。

当前规则：

- 基础上限为 **5 点**；
- 战技点的常规获取属于回能体系的一部分；
- 适用来源恢复战技点时，可以受到 **回能效率** 影响；
- 某些角色天赋可以提高战技点上限；
- 某些技能可以直接额外恢复战技点。

具体每种行为恢复多少战技点、自然获取节奏和角色差异后续再定。

---

### 5.5 终结技能量

属于角色战斗资源。

用途：

> 达到条件后释放终结技。

回能效率可以提高适用的能量恢复。

---

### 5.6 当前同步值

属于角色当前状态，不是成长属性。

```text
同步值上限
→ 属性

当前同步值
→ 当前战斗状态
```

---

## 6. 属性之间的职责边界

### 攻击节奏

```text
角色速度
→ 非召唤武器的基础攻击频率

武器冷却降低
→ 对适用武器的攻击间隔进行独立乘算缩短

召唤物自身速度
→ 召唤武器自己的基础攻击频率

召唤物速度增幅
→ 专门放大召唤物自身速度

投射物飞行速度倍率
→ 发出的弹体飞多快

攻击范围倍率
→ 能攻击多远 / 多大区域
```

这些属性分别处理不同环节，不合并成一个万能“速度”属性。

### 破韧

```text
武器削韧值
→ 击破速度

击破特攻
→ 击破收益

效果命中
→ 概率型负面效果是否成功施加
```

三者解决不同问题。

### 生存

```text
同步值上限
→ 能承受多少同步损伤

防御力
→ 每次受到多少同步损伤

移动速度
→ 能否主动避开伤害
```

本项目不额外加入传统玩家生命值和效果抵抗作为平行防御轴。

## 7. 当前属性清单

### 7.1 当前正式属性

| 类别 | 属性 |
|---|---|
| 生存 | 同步值上限 |
| 基础战斗 | 攻击力、防御力、速度 |
| 攻击节奏 | 武器冷却降低、召唤物速度增幅 |
| 输出 | 暴击率、暴击伤害 |
| 负面效果 | 效果命中 |
| 击破 | 击破特攻 |
| 战斗资源 | 回能效率 |
| 实时移动 | 移动速度增幅 |
| 空间攻击 | 攻击范围倍率、投射物飞行速度倍率 |
| 成长 / 收集 | 拾取范围、经验获取倍率、资源获取倍率 |

### 7.2 设计预留、当前版本暂不实现

- 物理属性伤害提高
- 火属性伤害提高
- 冰属性伤害提高
- 雷属性伤害提高
- 风属性伤害提高
- 量子属性伤害提高
- 虚数属性伤害提高

### 7.3 当前明确不加入

- 玩家生命值：由同步值承担主要生存职责；
- 效果抵抗：常规战斗不让玩家承受概率型控制 / 负面效果；
- 通用攻击速度属性：与速度重复；
- 将削韧值做成角色基础属性：削韧属于具体攻击 / 武器。

---

## 8. 属性可以从哪里获得

当前只确定来源类型，不提前固定具体数值：

- 角色基础属性；
- 角色等级成长；
- 被动 / 共鸣配饰；
- 武器或超武附带修正；
- 阵列事件；
- 临时 Buff；
- 其他明确声明的构筑来源。

不是每个属性都必须拥有一个专属被动。

被动应根据自身构筑定位选择合适属性，而不是为了“覆盖属性表”机械分配。
