# 独立被动配饰设计

> 状态：active Game Design。
>
> 本文记录不作为传说武器合成材料、而是直接参与局内构筑的独立被动配饰。
>
> 外部原始资料见 `docs/reference/accessories/galactic-baseballer/standalone-accessories.md`。

## 1. 基础版独立被动

《银河球棒侠传说》基础版共有 3 个不参与任何超武合成的独立被动配饰：

- 擂者之拳；
- 勤勉的嘉奖；
- 超剂量处方。

它们不需要额外建立武器共鸣、标签门控或超武进化规则。

---

## 2. 擂者之拳

擂者之拳直接提高正式属性 **经验获取倍率**。

| 等级 | 经验获取倍率 |
|---:|---:|
| Lv1 | +30% |
| Lv2 | +60% |
| Lv3 | +90% |
| Lv4 | +120% |

完整保留源版数值。

它只改变经验获得效率：

- 不提高拾取范围；
- 不提高资源获取倍率；
- 不改变经验掉落物本身的空间行为；
- 不附带其他战斗效果。

---

## 3. 勤勉的嘉奖

勤勉的嘉奖直接提高正式属性 **资源获取倍率**。

| 等级 | 资源获取倍率 |
|---:|---:|
| Lv1 | +10% |
| Lv2 | +20% |
| Lv3 | +30% |
| Lv4 | +40% |

完整保留源版数值。

资源获取倍率仍遵循 `docs/design/attributes.md` 的统一边界：

> 只有明确声明受资源获取倍率影响的局内资源，才会获得该加成。

因此它：

- 不自动影响经验；
- 不自动作用于所有未来货币；
- 不需要建立“Token 专属倍率”这一额外属性；
- 新资源是否受其影响，由对应资源系统自行声明。

---

## 4. 超剂量处方

超剂量处方完整保留源版的高风险全局增伤结构。

| 等级 | 玩家侧角色 / 武器伤害 | 敌人造成伤害 |
|---:|---:|---:|
| Lv1 | +25% | +100% |
| Lv2 | +50% | +100% |
| Lv3 | +75% | +100% |
| Lv4 | +100% | +100% |

规则：

- 玩家侧增伤随等级提高；
- 敌人造成伤害从 Lv1 起始终提高 **100%**，升级不会继续增加；
- “角色 / 武器伤害”覆盖归属于玩家角色与玩家武器的伤害来源；
- 敌人侧效果提高的是 **敌人造成的伤害本身**，之后仍进入项目正常的防御力 / 同步损伤结算；
- 因此不直接把规则写成“最终同步值损失强制翻倍”；
- 环境伤害、场景机关等不属于敌人的伤害来源，不因为装备超剂量处方而自动翻倍；
- 不附带额外掉落、经验或其他补偿效果。

其风险收益结构保持为：

```text
Lv1 起
敌人伤害 ×2
+
玩家侧伤害逐级提高
```

这是一个明确的高风险输出构筑，不再额外增加隐藏条件或保护机制。

## 5. 当前基础版配饰状态

基础版配饰共 **16 个**：

- 13 个武器共鸣配饰：跟随对应武器设计；
- 3 个独立被动配饰：本文已全部收敛。

至此，《银河球棒侠传说》基础版的 **武器 + 配饰** 资料与当前阶段设计处置已经完整覆盖。明确延期的内容也视为已完成当前阶段决策，而不是待办。

明确延期项：

- **纯美的祝祷**：当前不进行实时化设计，与筑城之志一并等待未来再重新开启；
- **筑城之志 / 永恒之心**：等待护盾、烧血、回血类生存资源玩法正式进入设计后再开启。

这两项都不进入当前阶段后续任务列表。
