## 1. 身份

- 名称：**甜美的沉眠**
- 参考 ID：`sweet_slumber`
- 属性：**量子**
- 标签：**范围**
- 最大等级：Lv.8
- 糖霜星球初始武器
- 超武进化所需被动（原活动称“共鸣配饰”）：**硝烟飘带**
- 进化条件：**甜美的沉眠 Lv.8 + 硝烟飘带 Lv.1+**
- 传说武器英文名：**Surprise in a Box**
- 传说武器中文名：**盒中惊喜**
- 来源版本：基础版，不使用《魔王篇》重平衡数据

## 2. 标签

官方基础版标签：

- **范围**

这是目前已经整理的第一把只带 `范围` 标签的武器。

源活动中的 `范围` 不只是描述“能打多个敌人”，还会与专属配饰 **硝烟飘带**直接联动：范围类武器每额外命中一个目标，伤害提高。

## 3. 源武器核心行为

甜美的沉眠属于 **击杀触发型范围武器**。

触发条件：我方角色或武器击败一个敌方目标。

触发后，以被击败敌人为来源，对其相邻敌人造成量子属性范围伤害。伤害由两部分组成：被击败目标最大生命值百分比 + 基础伤害倍率。

Lv1：被击败目标最大生命值 60% + 基础伤害 300%。

因此它的核心是：**击杀 → 尸体爆炸 / 连锁清群**。

## 4. 等级成长

| 等级 | 被击败目标最大生命值比例 | 基础伤害倍率 |
|---:|---:|---:|
| Lv1 | 60% | 300% |
| Lv2 | 60% | 500% |
| Lv3 | 80% | 500% |
| Lv4 | 80% | 800% |
| Lv5 | 100% | 800% |
| Lv6 | 100% | 1000% |
| Lv7 | 120% | 1000% |
| Lv8 | 120% | 1500% |

Lv8 最终为：120% 被击败目标最大生命值 + 1500% 基础伤害。

## 5. 超武进化所需被动：硝烟飘带

**硝烟飘带**拥有 `范围` 标签，并直接强化所有范围类武器。

| 等级 | 每额外命中 1 个目标的伤害提高 |
|---:|---:|
| Lv1 | +6% |
| Lv2 | +8% |
| Lv3 | +10% |
| Lv4 | +12% |

概念上：范围武器实际命中目标数为 N，则额外目标数 = max(N - 1, 0)，硝烟飘带增伤 = 额外目标数 × 当前等级倍率。

这是明确的标签门控被动：只有 `范围` 标签武器受到该效果。

## 6. 传说形态：盒中惊喜

进化条件：甜美的沉眠 Lv.8 + 硝烟飘带 Lv.1+。

基础版传说形态：

- 属性：**量子、虚数**
- 标签：**范围**
- 仍由我方角色或武器击败敌人触发
- 不再只攻击相邻敌人，改为攻击 **全体敌人**
- 每个敌人受到：**200% 被击败目标最大生命值 + 3000% 基础伤害**

与普通形态相比，核心变化是：相邻范围爆炸 → 全体攻击；量子 → 量子 + 虚数；120% + 1500% → 200% + 3000%。

## 7. 对本项目的设计价值

### 7.1 击杀触发型武器

它提供了新的 combat event-driven weapon 样本：敌人死亡事件直接驱动武器触发。

### 7.2 尸爆 / 连锁清群

伤害读取被击杀目标最大生命值，因此鼓励先击杀合适目标，再用爆炸清理周围敌人。

### 7.3 范围标签构筑

硝烟飘带说明 `范围` 标签可以直接作为被动筛选条件。这与当前项目已确立的 `发射`、`召唤` 标签门控结构一致。
