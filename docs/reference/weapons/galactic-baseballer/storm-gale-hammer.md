## 1. 身份

- 名称：**疾风巨锤**
- 参考 ID：`storm_gale_hammer`
- 属性：**风**
- 标签：**召唤、集中**
- 最大等级：Lv.8
- 超武进化所需被动（原活动称“共鸣配饰”）：**飓霆拷链**
- 进化条件：**疾风巨锤 Lv.8 + 飓霆拷链 Lv.1+**
- 传说武器英文名：**Prison-Shatter Hammer**
- 传说武器官方中文名：**待从官方 Wiki 动态页稳定回填**
- 来源版本：基础版，不使用《魔王篇》重平衡数据

## 2. 标签

官方基础版标签：

- **召唤**
- **集中**

本项目已经建立显式标签规则，因此这两个标签意味着：

- `召唤`：属于常驻召唤武器体系，可以受到召唤类速度强化；
- `集中`：表示武器主要围绕单一高价值目标进行集中输出。

其中 `集中` 的具体通用被动 / 属性尚未进入当前设计，不提前增加没有消费者的规则。

## 3. 源武器核心行为

基础版会召唤一个拥有独立速度的 **疾风巨锤**。

它行动时：

1. 选择当前生命值最高的敌方目标；
2. 对该目标造成高倍率风属性伤害；
3. 对精英 / 首领额外造成 **+30%** 伤害；
4. 给目标施加 **震荡（Reverberation）**；
5. 当其他敌人受到伤害时，带有震荡的目标会额外受到该次伤害一定比例的风属性伤害。

基础版 Lv1：

- 速度：**120**
- 主攻击：**2000% 基础伤害**
- 震荡传导比例：**5%**
- 精英 / 首领额外伤害：**+30%**

行为模型：

```text
疾风巨锤按自身速度行动
    ↓
选择当前生命值最高目标
    ↓
造成高额风属性单体伤害
    ↓
施加震荡
    ↓
其他敌人受到伤害
    ↓
震荡目标额外受到一定比例的传导伤害
```

这使它不是传统纯单体武器，而是：

> **把对群伤害的一部分重新汇聚到一个重点目标上。**

## 4. 等级成长

| 等级 | 速度 | 主攻击倍率 | 震荡传导比例 | 对精英 / 首领 |
|---:|---:|---:|---:|---:|
| Lv1 | 120 | 2000% | 5% | +30% |
| Lv2 | 120 | 4000% | 5% | +30% |
| Lv3 | 120 | 4000% | 7% | +30% |
| Lv4 | 180 | 4000% | 7% | +30% |
| Lv5 | 180 | 6000% | 7% | +30% |
| Lv6 | 180 | 6000% | 10% | +30% |
| Lv7 | 240 | 6000% | 10% | +30% |
| Lv8 | 240 | 8000% | 10% | +30% |

主要结构性成长点：

- **Lv3**：震荡传导 5% → 7%；
- **Lv4**：速度 120 → 180；
- **Lv6**：震荡传导 7% → 10%；
- **Lv7**：速度 180 → 240。

Lv2 / Lv5 / Lv8 主要提高主攻击倍率。

## 5. 超武进化所需被动：飓霆拷链

**飓霆拷链**同时提高我方角色与武器造成的风 / 雷属性伤害。

| 等级 | 风 / 雷属性伤害提高 |
|---:|---:|
| Lv1 | +30% |
| Lv2 | +40% |
| Lv3 | +50% |
| Lv4 | +60% |

它不是只强化疾风巨锤，而是一个跨角色、跨武器的 **风雷属性构筑被动**。

因此在本项目中，它天然可以同时强化：

- 疾风巨锤；
- 游侠长弓；
- 雷电荆棘；
- 其他未来的风 / 雷角色与武器。

这也与本项目已经预留的七属性伤害提高体系一致。

## 6. 传说形态

进化：

```text
疾风巨锤 Lv.8
+
飓霆拷链 Lv.1+
↓
Prison-Shatter Hammer
（官方中文名待回填）
```

基础版传说效果：

- 属性：**风、雷**
- 标签：**召唤、集中**
- 速度：**240**
- 对当前生命值最高目标造成 **10000% 基础伤害**；
- 对精英 / 首领额外 **+30%**；
- 施加震荡；
- 有 **50% 固定概率**重复造成一次主攻击；
- 可以连续重复，最多 **4 次**；
- 震荡传导比例保持 **10%**；
- 当前震荡目标被击败后，震荡会转移到其他敌人。

超武强化方向：

```text
普通形态
高生命目标锁定
+ 单次重击
+ 群体伤害传导
    ↓
传说形态
风雷双属性
+ 10000% 主击
+ 50% 概率连续追击（最多 4 次）
+ 震荡死亡转移
```

## 7. 对本项目的设计价值

### 7.1 集中火力型召唤武器

疾风巨锤给出了一个明确的 `集中` 标签样本：

> 不追求均匀清群，而是自动寻找高价值目标，把整个战场的一部分输出重新汇聚到它身上。

在本项目当前“敌人数量较少、单体耐久高于传统幸存者”的方向下，这个机制尤其适合：

- 精英敌人；
- Boss；
- 高生命威胁目标。

### 7.2 召唤 + 集中的标签交叉

```text
召唤
→ 独立速度 / 独立行动

集中
→ 高价值目标锁定 / 单体构筑
```

它因此可以同时参与召唤构筑和集中构筑。

### 7.3 伤害汇聚

震荡并不是普通易伤：

```text
其他敌人受到伤害
↓
取其中一定比例
↓
额外传导给震荡目标
```

这与单纯：

> 目标受到伤害 +X%

有本质区别。

因此未来实时改造时应尽量保留 **“对群输出 → 汇聚到重点目标”** 这个识别度，而不是把它简化为普通易伤。

## 8. 本项目实时化需要讨论

源武器作为 `召唤` 武器，本项目可以直接沿用独立速度体系，但还需要明确：

1. 基础速度是否直接沿用 **120**，以及 Lv4 / Lv7 的 180 / 240 是否保留；
2. 实时环境中“当前生命值最高目标”是全场搜索，还是限制在攻击范围内；
3. 巨锤如何表现攻击：瞬时落锤、飞行锤体、冲击波，或其他形式；
4. 震荡一次只能存在于一个敌人，还是可以有多个；
5. 震荡目标死亡后，普通形态是否也自动转移；
6. 传导伤害是否受距离限制；
7. 传导伤害是否可以暴击、削韧或触发其他武器；
8. 主攻击与传导伤害分别使用多少削韧值；
9. 传说形态的“50% 连续追击、最多 4 次”如何实时表现。

这些属于下一步 Game Design，不从源资料直接替项目决定。
