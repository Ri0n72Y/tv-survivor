## 1. 身份

- 名称：**游侠长弓**
- 参考 ID：`ranger_longbow`
- 属性：**风**
- 标签：**范围、发射**
- 最大等级：Lv.8
- 超武进化所需被动：**裂风箭矢**
- 来源版本：基础版，不使用《魔王篇》重平衡数据

## 2. 官方标签

基础版标签：

- **范围**
- **发射**

这两个标签在本项目中作为显式武器标签保留。

其中：

- `发射` 直接决定它能受到 **发射类武器攻击次数**；
- `范围` 保留为范围构筑标签，具体专属被动等出现实际消费者后再设计。

## 3. 源武器等级成长

当前已记录的基础版成长：

| 等级 | 基础攻击次数 | 单次伤害倍率 |
|---:|---:|---:|
| Lv1 | 3 | 300% |
| Lv2 | 3 | 450% |
| Lv3 | 3 | 600% |
| Lv4 | 4 | 600% |
| Lv5 | 4 | 800% |
| Lv6 | 4 | 1000% |
| Lv7 | 5 | 1000% |
| Lv8 | 5 | 1200% |

源活动属于多次发射、随机目标、范围型攻击。

## 4. 超武进化所需被动：裂风箭矢

**裂风箭矢**强化发射类武器的攻击次数。

当前记录：

| 等级 | 发射类武器攻击次数 |
|---:|---:|
| Lv1 | +2 |
| Lv2 | +3 |
| Lv3 | +4 |
| Lv4 | +5 |

本项目直接把它解释为显式标签规则：

```text
武器具有「发射」标签
    ↓
获得裂风箭矢提供的发射类武器攻击次数
```

因此不需要为每把武器维护隐藏兼容关系。
