## 1. 身份

- 名称：**雷电荆棘**
- 参考 ID：`thunderbolt_thorns`
- 属性：**雷**
- 标签：**发射**
- 最大等级：Lv.8
- 齿轮星球初始武器
- 超武进化所需被动（原活动称“共鸣配饰”）：**冠冕碎晶**
- 进化条件：**雷电荆棘 Lv.8 + 冠冕碎晶 Lv.1+**
- 传说武器：**惊雷冠冕**
- 来源版本：基础版，不使用《魔王篇》重平衡数据

## 2. 源武器核心行为

雷电荆棘不是普通的直接射击武器。

基础行为：

1. 对一名敌人施加 **雷电荆棘**；
2. 该目标行动开始时，雷电荆棘触发；
3. 对目标造成雷属性持续伤害；
4. 本次伤害继续向其他敌人弹射若干次；
5. 每次弹射伤害为初始伤害的 **50%**；
6. 当前携带雷电荆棘的目标死亡时，效果转移至其他敌人。

行为模型：

```text
选择 / 获得携带者
    ↓
目标行动开始
    ↓
雷电荆棘触发
    ↓
主目标受到雷属性持续伤害
    ↓
向其他目标弹射 N 次
每次 = 主伤害 50%
    ↓
携带者死亡
    ↓
雷电荆棘转移到新的敌人
```

原活动实际还允许部分“持续伤害引爆”行为提前触发雷电荆棘，因此它本质上与 DoT 构筑存在强交互。

## 3. 等级成长

基础版完整成长：

| 等级 | 主体持续伤害倍率 | 弹射次数 | 弹射伤害 |
|---:|---:|---:|---:|
| Lv1 | 400% 基础伤害 | 3 | 主伤害的 50% |
| Lv2 | 800% | 3 | 50% |
| Lv3 | 1200% | 3 | 50% |
| Lv4 | 1200% | 5 | 50% |
| Lv5 | 1600% | 5 | 50% |
| Lv6 | 2000% | 5 | 50% |
| Lv7 | 2400% | 5 | 50% |
| Lv8 | 2400% | 7 | 50% |

主要结构性成长点：

- **Lv4**：弹射次数 3 → 5；
- **Lv8**：弹射次数 5 → 7。

其余等级主要提高主体持续伤害倍率。

## 4. 标签：发射

官方基础版标签只有：

- **发射**

这点对本项目非常重要。

它意味着雷电荆棘应进入 **发射构筑**，并受到：

> **发射类武器攻击次数**

这一标签门控属性影响。

但雷电荆棘不像人人为我或游侠长弓那样“发出 N 枚可见投射物”，因此本项目还需要明确：

> 对雷电荆棘而言，“发射类武器攻击次数”具体增加什么？

最自然的候选是 **增加一次触发产生的雷击 / 弹射次数**，这也与原活动 Lv4 / Lv8 的成长方向一致。

该实时解释目前只作为待讨论项，不在本参考文档中直接定案。

## 5. 超武进化所需被动：冠冕碎晶

**冠冕碎晶**是雷电荆棘的共鸣配饰。

基础版效果：

> 提高我方全体角色速度。

| 等级 | 角色速度 |
|---:|---:|
| Lv1 | +30 |
| Lv2 | +40 |
| Lv3 | +50 |
| Lv4 | +60 |

它与“我为人人”的结构形成清晰对照：

```text
冠冕碎晶
→ 角色速度

我为人人
→ 召唤类武器速度
```

在本项目中：

- 冠冕碎晶应进入 **角色速度** 构筑；
- 它不提高召唤物自身速度；
- 是否还附带其他为了实时玩法平衡而新增的效果，暂未设计。

## 6. 传说武器：惊雷冠冕

进化：

```text
雷电荆棘 Lv.8
+
冠冕碎晶 Lv.1+
↓
惊雷冠冕
```

基础版传说形态：

- 属性：**风、雷**
- 标签：**发射**
- 对一名敌人施加惊雷冠冕；
- 目标行动开始时，造成 **4000% 基础伤害**的风 / 雷持续伤害；
- 该伤害会引爆目标身上的其他持续伤害：
  - 引爆伤害为原持续伤害的 **100%**；
- 随后弹射 **7 次**；
- 每次弹射造成主伤害的 **50%**；
- 弹射时触发的其他持续伤害，其引爆伤害为原持续伤害的 **50%**；
- 当前携带者死亡时，惊雷冠冕转移给其他敌人。

与普通形态相比，超武不只是数值放大，还增加了：

> **主动引爆其他持续伤害**

这一新的构筑联动。

## 7. 对本项目的设计价值

雷电荆棘提供了目前前三把武器没有的行为 primitive：

### 7.1 持续附着 / 转移型武器

它不是：

- 一次性近战；
- 普通投射物；
- 独立召唤物。

而是：

```text
武器效果附着到敌人
↓
在目标身上周期性触发
↓
目标死亡后自动转移
```

### 7.2 弹射型发射武器

它说明 `发射` 标签并不等于“必须有实体弹体”。

发射构筑可以表示：

> 一次触发产生多少次可传播的攻击实例。

因此标签应该保持玩法语义，而不是实现语义。

### 7.3 DoT 联动

传说形态会主动引爆其他持续伤害，这为未来：

- 灼烧；
- 触电；
- 风化；
- 裂伤；
- 其他持续伤害型负面效果；

提供了明确的构筑交互参考。

## 8. 本项目实时化需要讨论

源机制依赖“敌人回合开始”，而实时类幸存者没有回合，因此至少要重新决定：

1. 雷电荆棘如何首次附着目标；
2. 附着后多久触发一次；
3. 周期是否受角色速度 / 武器冷却降低影响；
4. 发射类武器攻击次数究竟增加弹射数、雷击数，还是其他行为；
5. 目标死亡后的转移搜索范围；
6. 是否保留“触发其他持续伤害”的超武特性；
7. 触发时是否造成削韧；
8. 雷电荆棘本身是否被视为负面效果，以及是否受效果命中影响。

这些属于下一步 Game Design，不从原活动数据直接推导。
