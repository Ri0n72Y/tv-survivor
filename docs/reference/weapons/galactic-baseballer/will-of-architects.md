## 2. 源武器核心行为

筑城之志本身不是按速度周期行动的主动武器，而是由 **击杀事件** 触发。

当我方角色或武器击败敌方目标后：

1. 为 **1 名我方角色**提供「筑城」护盾；
2. 护盾持续 **5 回合**；
3. 持有该护盾的角色发动攻击时，筑城之志基于当前护盾量追加一次物理伤害；
4. 如果被攻击目标当前生命值低于基于护盾量计算出的斩杀阈值，则：
   - 消耗该护盾；
   - 对目标造成等于其当前生命值的 **物理真实伤害**；
5. 对精英与 Boss 目标的相关伤害额外提高 **30%**。

Lv1：

- 击杀后护盾量：**6% 基础伤害**
- 带盾攻击追加物理伤害：**4000% × 护盾效果**
- 斩杀阈值：目标当前生命值低于 **8000% × 护盾效果**
- 护盾持续：**5 回合**

结构：

```text
我方角色 / 武器击杀敌人
↓
为 1 名角色提供筑城护盾
↓
带盾角色发动攻击
├─ 正常情况：基于护盾量追加物理伤害
└─ 目标低于斩杀阈值：
   消耗护盾
   → 造成等于目标当前生命值的物理真实伤害
```

## 4. 共鸣配饰：永恒之心

永恒之心是局内续航 / 资源恢复配饰。

### 获取或升级时

每次：

- 首次获得永恒之心；
- 永恒之心升级；

都会立即：

- 完全恢复全体角色生命值；
- 完全恢复战技点；
- 完全恢复能量。

### 队伍等级提升时

| 等级 | 全体生命恢复 | 战技点恢复 | 能量恢复 |
|---:|---:|---:|---:|
| Lv1 | 6% | 1 | 8 |
| Lv2 | 9% | 2 | 12 |
| Lv3 | 12% | 3 | 16 |
| Lv4 | 15% | 4 | 20 |

它本身不直接强化护盾倍率，而是通过升级 / 队伍升级提供持续资源恢复。

## 5. 传说形态：Eternal Fortress

进化条件：

```text
筑城之志 Lv8
+
永恒之心 Lv1+
```

源版效果：

- 属性：**物理**
- 标签：**集中**
- 我方角色或武器击败敌方目标后，为 **全体我方角色**提供护盾；
- 护盾量：**24% 基础伤害**
- 持续：**5 回合**
- 持有护盾的角色发动攻击时：
  - 追加 **12000% × 护盾效果** 的物理伤害；
- 如果目标当前生命值低于：
  - **24000% × 护盾效果**
- 则消耗护盾，对目标造成：
  - **等于目标当前生命值的物理真实伤害**
- 对精英 / Boss 目标额外提高 **30%**。

相比 Lv8 普通筑城之志：

```text
普通 Lv8
击杀
→ 1 名角色获得 16% 护盾
→ 8000% 护盾量追加伤害
→ 16000% 护盾量斩杀阈值

Eternal Fortress
击杀
→ 全体角色获得 24% 护盾
→ 12000% 护盾量追加伤害
→ 24000% 护盾量斩杀阈值
```

## 6. 对本项目的设计价值

### 6.1 击杀 → 防御 → 进攻

它不是单纯的护盾武器，而是把三件事连起来：

```text
击杀
→ 获得护盾
→ 带盾角色攻击
→ 追加伤害 / 残血执行
```

因此其核心身份是 **击杀驱动的攻防转换武器**。

### 6.2 与同步值体系存在直接设计冲突

本项目已经确定玩家主要生存资源是 **同步值**，而不是传统角色 HP。

因此源版“给角色护盾”的语义不能直接机械照搬，需要决定：

- 护盾是否成为独立于同步值之外的临时吸收层；
- 是否改为临时同步值护盾 / 同步值缓冲；
- 是否让筑城之志只保留“护盾量作为攻击资源”，而不承担传统生命保护；
- 多角色选择制下，“给 1 名我方角色”在单角色实时战斗中如何映射。

这些都属于本项目实时改造，当前不在源资料层替代决定。

### 6.3 残血执行

普通形态与超武都带有“低于护盾量阈值时消耗护盾，造成等于目标当前生命值的真实伤害”。

实时化时需要单独确定：

- 对普通敌人、精英、Boss 是否完全沿用；
- “真实物理伤害”是否参与削韧；
- 是否会触发击杀类武器，例如甜美的沉眠；
- 执行发生在角色攻击命中前、命中后还是作为追加结算。
