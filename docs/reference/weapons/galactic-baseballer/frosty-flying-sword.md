## 1. 身份

- 名称：**寒冰飞剑**
- 参考 ID：`frosty_flying_sword`
- 属性：**冰**
- 标签：**发射**
- 最大等级：Lv.8
- 微缩星球初始武器
- 超武进化所需被动（原活动称“共鸣配饰”）：**冰火令符**
- 进化条件：**寒冰飞剑 Lv.8 + 冰火令符 Lv.1+**
- 传说武器英文名：**Flaming Greatsword**
- 传说武器中文名：**炽焰大剑**
- 来源版本：基础版，不使用《魔王篇》重平衡数据

## 2. 标签

官方基础版标签：

- **发射**

因此在本项目现有标签体系中，它天然属于发射构筑，并可以受到：

- 发射类武器攻击次数；

但具体如何映射“额外连续行动带来的额外飞剑”与本项目实时发射次数，需要在实时改造时单独决定。

## 3. 源武器核心行为

寒冰飞剑不是按自身速度行动，而是由 **我方角色连续行动** 触发。

基础行为：

1. 我方角色连续行动达到 3 次；
2. 在敌方下一次行动前触发寒冰飞剑；
3. 向随机敌方目标发射多枚飞剑；
4. 每一枚飞剑造成冰属性伤害；
5. 在已满足 3 次连续行动后，每额外 1 次连续行动，再额外增加 1 枚飞剑。

Lv1：

- 基础飞剑数量：**3**
- 单枚伤害：**300% 基础伤害**

概念上：

```text
连续行动 3 次
    ↓
寒冰飞剑触发
    ↓
基础发射 3 枚飞剑
    ↓
每额外连续行动 1 次
    ↓
额外 +1 枚飞剑
```

## 4. 等级成长

| 等级 | 基础发射数量 | 单枚伤害倍率 |
|---:|---:|---:|
| Lv1 | 3 | 300% |
| Lv2 | 3 | 450% |
| Lv3 | 3 | 600% |
| Lv4 | 5 | 600% |
| Lv5 | 5 | 750% |
| Lv6 | 5 | 900% |
| Lv7 | 7 | 900% |
| Lv8 | 7 | 1200% |

主要结构性成长点：

- **Lv4**：基础飞剑数量 3 → 5；
- **Lv7**：基础飞剑数量 5 → 7；
- 其他等级主要提升单枚飞剑伤害。

## 5. 超武进化所需被动：冰火令符

冰火令符同时提高我方角色与武器造成的：

- 冰属性伤害；
- 火属性伤害。

| 等级 | 冰 / 火属性伤害提高 |
|---:|---:|
| Lv1 | +30% |
| Lv2 | +40% |
| Lv3 | +50% |
| Lv4 | +60% |

它是一个跨角色、跨武器的冰火属性构筑被动。

在本项目中，它与已经预留的七属性伤害提高体系天然兼容，但是否直接采用该数值与作用域，等正式实时改造时再确定。

## 6. 传说形态：Flaming Greatsword

进化条件：

```text
寒冰飞剑 Lv.8
+
冰火令符 Lv.1+
↓
Flaming Greatsword
```

基础版传说效果：

- 属性：**火、冰**
- 标签：**发射**
- 我方角色连续行动达到 3 次后触发；
- 基础发射 **7 枚**飞剑；
- 每枚飞剑造成 **1500% 基础伤害**；
- 每枚飞剑随机造成火属性或冰属性伤害；
- 在满足基础触发后，每额外 1 次连续行动：
  - 额外增加 **2 枚**飞剑；
- 对精英 / Boss 额外造成 **+30%** 伤害。

与普通形态相比：

```text
寒冰飞剑
冰属性
基础 7 枚
每额外行动 +1 枚
1200%

↓

Flaming Greatsword
冰 + 火
基础 7 枚
每额外行动 +2 枚
1500%
对精英 / Boss +30%
```

## 7. 对本项目的设计价值

### 7.1 行动累计型发射武器

它与游侠长弓这种固定周期自动攻击不同，核心不是自身攻击速度，而是：

> **其他行为累计 → 一次性释放大量发射实例。**

这提供了一个新的实时 primitive：

```text
事件累计
↓
达到阈值
↓
爆发式发射
```

### 7.2 发射标签的另一种消费者

寒冰飞剑再次说明：

> `发射` 标签描述的是“一次触发产生多个攻击实例”的构筑语义，而不要求武器本身必须按照固定周期自动攻击。

### 7.3 冰火属性构筑

冰火令符可以自然连接：

- 寒冰飞剑；
- 人人为我；
- 寒霜灭火器；
- 未来其他冰 / 火角色与武器。

## 8. 本项目实时化

### 8.1 角色核心武器充能

本项目保留寒冰飞剑的“累计触发”身份，但把原活动的“我方角色连续行动”映射为：

> **角色核心武器命中敌人的数量。**

计数规则：

- 同一次角色核心武器攻击中，每个实际命中的敌人贡献 **1 点充能**；
- 同一个敌人在同一次核心武器攻击中最多计 1 次；
- 一次攻击命中 N 个不同敌人，就获得 N 点充能；
- 后续新的核心武器攻击再次命中同一个敌人，可以再次获得充能。

当前沿用源武器的 3 点基础阈值：

```text
角色核心武器攻击
    ↓
统计本次命中的不同敌人数 N
    ↓
寒冰飞剑充能 +N
    ↓
总充能 >= 3
    ↓
触发寒冰飞剑
```

以当前开拓者 / 小浣熊为例，充能来源就是其角色核心武器 **球棒** 的命中。

这使寒冰飞剑的构筑方向明确依赖：

- 角色自身核心武器；
- 核心武器攻击频率；
- 核心武器一次攻击能够命中的敌人数；

而不是主要依赖普通构筑武器自身的攻击频率。

### 8.2 爆发发射

当充能达到 3 点或以上时触发。触发时：

1. 读取当前全部充能；
2. 按“超过 3 点的额外充能”计算额外飞剑；
3. 一次性消耗全部充能；
4. 连续爆发式发射飞剑。

普通寒冰飞剑：

```text
额外充能
= max(触发时充能 - 3, 0)

实际飞剑数量
= 当前等级基础飞剑数量
+ 额外充能
+ 发射类武器攻击次数
```

例如 Lv1 基础 3 枚：

```text
充能 3 → 3 枚 + 发射类武器攻击次数
充能 4 → 4 枚 + 发射类武器攻击次数
充能 5 → 5 枚 + 发射类武器攻击次数
```

当前确认：

- 飞剑不是同时瞬发，而是 **连续爆发式发射**；
- 每一枚飞剑只命中 **一个目标**；
- 本项目因此为寒冰飞剑补充玩法标签 **`集中`**；
- 每次准备发射下一枚飞剑时，选择 **距离玩家最近的有效敌人**；
- 如果连射过程中当前目标死亡，下一枚飞剑重新寻找当前最近敌人；
- 当前等级基础飞剑数量继续沿用源数据 3 → 5 → 7；
- `发射类武器攻击次数`直接增加基础发射数量。

### 8.3 削韧

每枚飞剑的基础削韧值为 **5**，但只有飞剑属性与敌人对应弱点匹配时才造成削韧。

普通寒冰飞剑：

- 冰属性飞剑命中具有冰弱点的敌人：削韧 5；
- 命中不具有冰弱点的敌人：不削韧。

炽焰大剑：

- 每枚飞剑独立随机为火属性或冰属性；
- 火属性飞剑命中火弱点：削韧 5；
- 冰属性飞剑命中冰弱点：削韧 5；
- 属性与弱点不匹配时不削韧。

### 8.4 与游侠长弓的构筑区分

两把 `发射` 武器有明确不同：

```text
游侠长弓
→ 普通自动武器
→ 主要依赖武器自身构筑
→ 速度 / 冷却 / 发射次数

寒冰飞剑
→ 角色核心武器联动
→ 主要依赖角色自身武器攻击
→ 核心武器命中越频繁，寒冰飞剑越频繁触发
```

因此寒冰飞剑不是游侠长弓的另一把周期投射武器，而是一个 **角色核心武器驱动的爆发发射器**。

### 8.5 超武：炽焰大剑

炽焰大剑保持与寒冰飞剑完全相同的实时行为框架：

- 仍由角色核心武器命中敌人获得充能；
- 3 点充能达到基础触发阈值；
- 发射时消耗全部充能；
- 连续向当前最近敌人爆发式发射；
- 每枚飞剑只命中一个目标；
- 目标死亡后下一枚重新寻找最近敌人。

沿用源参数：

- 基础发射数量：**7 枚**；
- 单枚伤害：**1500% 基础伤害**；
- 每枚飞剑独立随机造成 **火属性或冰属性伤害**；
- 对精英 / Boss 额外造成 **+30%** 伤害；
- 每超过基础阈值 1 点充能，额外增加 **2 枚飞剑**。

公式：

```text
额外充能
= max(触发时充能 - 3, 0)

实际飞剑数量
= 7
+ 额外充能 × 2
+ 发射类武器攻击次数
```

项目标签：

- 源标签：`发射`
- 本项目补充：`集中`

因为每一枚飞剑都是单目标攻击，不产生范围伤害。
