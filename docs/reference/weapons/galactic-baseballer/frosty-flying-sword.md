## 1. 身份

- 名称：**寒冰飞剑**
- 参考 ID：`frosty_flying_sword`
- 属性：**冰**
- 标签：**发射**
- 最大等级：Lv.8
- 微缩星球初始武器
- 超武进化所需被动（原活动称“共鸣配饰”）：**冰火令符**
- 进化条件：**寒冰飞剑 Lv.8 + 冰火令符 Lv.1+**
- 传说武器英文名：**Flaming Greatsword**
- 传说武器中文名：**待官方中文口径回填**
- 来源版本：基础版，不使用《魔王篇》重平衡数据

## 2. 标签

官方基础版标签：

- **发射**

因此在本项目现有标签体系中，它天然属于发射构筑，并可以受到：

- 发射类武器攻击次数；

但具体如何映射“额外连续行动带来的额外飞剑”与本项目实时发射次数，需要在实时改造时单独决定。

## 3. 源武器核心行为

寒冰飞剑不是按自身速度行动，而是由 **我方角色连续行动** 触发。

基础行为：

1. 我方角色连续行动达到 3 次；
2. 在敌方下一次行动前触发寒冰飞剑；
3. 向随机敌方目标发射多枚飞剑；
4. 每一枚飞剑造成冰属性伤害；
5. 在已满足 3 次连续行动后，每额外 1 次连续行动，再额外增加 1 枚飞剑。

Lv1：

- 基础飞剑数量：**3**
- 单枚伤害：**300% 基础伤害**

概念上：

```text
连续行动 3 次
    ↓
寒冰飞剑触发
    ↓
基础发射 3 枚飞剑
    ↓
每额外连续行动 1 次
    ↓
额外 +1 枚飞剑
```

## 4. 等级成长

| 等级 | 基础发射数量 | 单枚伤害倍率 |
|---:|---:|---:|
| Lv1 | 3 | 300% |
| Lv2 | 3 | 450% |
| Lv3 | 3 | 600% |
| Lv4 | 5 | 600% |
| Lv5 | 5 | 750% |
| Lv6 | 5 | 900% |
| Lv7 | 7 | 900% |
| Lv8 | 7 | 1200% |

主要结构性成长点：

- **Lv4**：基础飞剑数量 3 → 5；
- **Lv7**：基础飞剑数量 5 → 7；
- 其他等级主要提升单枚飞剑伤害。

## 5. 超武进化所需被动：冰火令符

冰火令符同时提高我方角色与武器造成的：

- 冰属性伤害；
- 火属性伤害。

| 等级 | 冰 / 火属性伤害提高 |
|---:|---:|
| Lv1 | +30% |
| Lv2 | +40% |
| Lv3 | +50% |
| Lv4 | +60% |

它是一个跨角色、跨武器的冰火属性构筑被动。

在本项目中，它与已经预留的七属性伤害提高体系天然兼容，但是否直接采用该数值与作用域，等正式实时改造时再确定。

## 6. 传说形态：Flaming Greatsword

进化条件：

```text
寒冰飞剑 Lv.8
+
冰火令符 Lv.1+
↓
Flaming Greatsword
```

基础版传说效果：

- 属性：**火、冰**
- 标签：**发射**
- 我方角色连续行动达到 3 次后触发；
- 基础发射 **7 枚**飞剑；
- 每枚飞剑造成 **1500% 基础伤害**；
- 每枚飞剑随机造成火属性或冰属性伤害；
- 在满足基础触发后，每额外 1 次连续行动：
  - 额外增加 **2 枚**飞剑；
- 对精英 / Boss 额外造成 **+30%** 伤害。

与普通形态相比：

```text
寒冰飞剑
冰属性
基础 7 枚
每额外行动 +1 枚
1200%

↓

Flaming Greatsword
冰 + 火
基础 7 枚
每额外行动 +2 枚
1500%
对精英 / Boss +30%
```

## 7. 对本项目的设计价值

### 7.1 行动累计型发射武器

它与游侠长弓这种固定周期自动攻击不同，核心不是自身攻击速度，而是：

> **其他行为累计 → 一次性释放大量发射实例。**

这提供了一个新的实时 primitive：

```text
事件累计
↓
达到阈值
↓
爆发式发射
```

### 7.2 发射标签的另一种消费者

寒冰飞剑再次说明：

> `发射` 标签描述的是“一次触发产生多个攻击实例”的构筑语义，而不要求武器本身必须按照固定周期自动攻击。

### 7.3 冰火属性构筑

冰火令符可以自然连接：

- 寒冰飞剑；
- 人人为我；
- 寒霜灭火器；
- 未来其他冰 / 火角色与武器。

## 8. 本项目实时化需要讨论

1. 原活动的“我方角色连续行动 3 次”在实时玩法中如何转换；
2. 是否改为普通周期自动武器，还是保留“累计触发”身份；
3. 如果保留累计机制，什么事件算作一次“行动”；
4. 基础飞剑数量 3 → 5 → 7 是否原样保留；
5. 源机制“每额外行动 +1 枚飞剑”如何映射实时玩法；
6. `发射类武器攻击次数`与源机制额外飞剑如何叠加；
7. 每枚飞剑如何选择目标，是否允许重复目标；
8. 飞剑是否为实体投射物，是否受投射物飞行速度倍率；
9. 主攻击 / 每枚飞剑削韧值；
10. 传说形态的火 / 冰随机属性如何表现；
11. 传说武器正式中文名。

这些属于下一步 Game Design，不从源资料直接替项目决定。
