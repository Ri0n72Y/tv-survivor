# 虚无的预警

> 类型：外部参考资料。
>
> 来源版本：**《银河球棒侠传说》基础版 / 《崩坏：星穹铁道》2.2（2024）**。
>
> 主数据源：Adventure Index；Game8 与 HoYoLAB 基础版攻略交叉核对。
>
> 本文先记录源武器；本项目实时类幸存者改造尚未正式收敛。

## 1. 身份

- 名称：**虚无的预警**
- 参考 ID：`nihilitys_warning`
- 属性：**量子**
- 标签：**集中**
- 最大等级：Lv.8
- 共鸣配饰：**不知疲倦**
- 进化条件：**虚无的预警 Lv.8 + 不知疲倦 Lv.1+**
- 传说武器英文名：**Time's Eternity**
- 传说武器中文名：**待官方中文口径最终确认**
- 来源版本：基础版，不使用后续《魔王篇》重平衡数据

## 2. 源武器核心行为

虚无的预警围绕敌方负面状态「懊丧」运作。

当我方命中敌人时：

1. 以固定概率给该目标施加 1 层「懊丧」；
2. 当敌人被施加其他 Debuff 时，也会额外获得「懊丧」；
3. 每层「懊丧」提高该目标受到的全部伤害；
4. 最多叠加 **20 层**；
5. 达到 20 层时：
   - 虚无的预警对该目标造成一次高额量子伤害；
   - 对精英 / Boss 额外提高 30%；
   - 普通形态随后清除全部「懊丧」。

Lv1：

- 命中时施加「懊丧」的固定概率：**70%**
- 每层受到伤害提高：**0.4%**
- 最大层数：**20**
- 20 层触发伤害：**3000% 基础伤害**
- 精英 / Boss：**+30%**

结构：

```text
我方攻击命中敌人
或
敌人获得其他 Debuff
↓
叠加「懊丧」
↓
每层提高目标受到的伤害
↓
达到 20 层
↓
虚无的预警触发量子爆发
↓
普通形态清空懊丧
```

## 3. Lv1–Lv8

| 等级 | 命中施加懊丧固定概率 | 每层易伤 | 20层触发伤害 |
|---:|---:|---:|---:|
| Lv1 | 70% | 0.4% | 3000% |
| Lv2 | 70% | 0.4% | 4500% |
| Lv3 | 70% | 0.6% | 4500% |
| Lv4 | 80% | 0.6% | 4500% |
| Lv5 | 80% | 0.6% | 6000% |
| Lv6 | 80% | 0.8% | 6000% |
| Lv7 | 90% | 0.8% | 6000% |
| Lv8 | 90% | 0.8% | 7500% |

成长结构：

- Lv2 / Lv5 / Lv8：提高 20 层触发伤害；
- Lv3 / Lv6：提高每层易伤；
- Lv4 / Lv7：提高我方命中时施加「懊丧」的固定概率。

注意：

- 「固定概率」按源版语义记录；
- 它不同于寒霜灭火器那种“基础概率 + 效果命中 / 效果抵抗”结构；
- 是否在本项目实时版中继续作为固定概率，需要在实时改造阶段单独确认。

## 4. 共鸣配饰：不知疲倦

不知疲倦只强化 `集中` 标签武器对精英 / Boss 的伤害。

| 等级 | 集中类武器对精英 / Boss 伤害提高 |
|---:|---:|
| Lv1 | 35% |
| Lv2 | 40% |
| Lv3 | 45% |
| Lv4 | 50% |

它是明确的标签型配饰：

```text
武器具有「集中」
+
目标是精英 / Boss
↓
获得不知疲倦伤害强化
```

因此它天然可以服务虚无的预警，也可以服务其他拥有 `集中` 标签的武器。

## 5. 传说形态：Time's Eternity

进化条件：

```text
虚无的预警 Lv8
+
不知疲倦 Lv1+
```

源版效果：

- 属性：**量子 + 虚数**
- 标签：**集中**
- 我方命中敌人时：
  - **90% 固定概率**施加「懊丧」；
- 敌人获得其他 Debuff 时：
  - 同样获得「懊丧」；
- 每层「懊丧」：
  - 使目标受到的全部伤害提高 **0.8%**；
- 最大：
  - **20 层**；
- 达到 20 层时：
  - 对目标造成 **7500% 基础伤害**的量子 + 虚数伤害；
  - 对精英 / Boss 额外提高 **30%**；
  - 与普通形态不同，**只减少 10 层懊丧**，而不是全部清空。

因此超武形成：

```text
20 层
↓
触发高额量子 + 虚数伤害
↓
只降到 10 层
↓
重新叠 10 层即可再次触发
```

相比普通 Lv8：

```text
虚无的预警 Lv8
20 层 → 7500%量子伤害 → 清零

Time's Eternity
20 层 → 7500%量子+虚数伤害 → 保留10层
```

## 6. 对本项目的设计价值

### 6.1 Debuff 构筑核心

它不是传统主动攻击武器，而是一个：

> **命中 / Debuff → 叠层易伤 → 阈值爆发**

的构筑核心。

它与寒霜灭火器天然形成联动：

```text
寒霜灭火器
→ 冻结 / 灼烧 Debuff

虚无的预警
→ 因 Debuff 额外叠加懊丧
```

### 6.2 固定概率与效果命中需要明确区分

源版明确写的是 **fixed chance / 固定概率**。

因此如果本项目保留这一语义：

- 不应受到效果命中影响；
- 不应受到敌人效果抵抗影响。

这与寒霜灭火器的冻结 / 灼烧正好形成两类概率机制。

### 6.3 阈值爆发属于集中攻击

达到 20 层后，虚无的预警只对该叠满目标触发高额伤害。

因此按本项目当前默认削韧原则：

- 若实时版没有另行指定；
- 该阈值爆发作为 `集中` 单体攻击，基础削韧默认 **20**；
- 仍需对应弱点匹配才实际削韧。

这里只记录当前默认基准；实时化时仍可显式覆盖。

## 7. 本项目实时化待讨论

1. 「懊丧」应由什么算一次“我方命中”；
2. 一次范围攻击命中多个敌人时，每个敌人是否独立判定叠层；
3. 多段攻击是每段叠层，还是每次完整攻击行为只叠一次；
4. “敌人获得其他 Debuff”是否每个 Debuff 实例都额外叠 1 层；
5. DoT 刷新 / 延长是否算新的 Debuff 施加；
6. 击破异常是否算其他 Debuff；
7. 是否完整保留 70% → 80% → 90% 固定概率；
8. 每层易伤 0.4% → 0.8% 是否原样保留；
9. 20 层阈值是否适合实时高频攻击，还是需要重新平衡；
10. 20 层爆发是否直接沿用集中攻击基础削韧 20；
11. 超武保留 10 层后是否允许高频连续触发；
12. 不知疲倦是否完整保留为 `集中` 标签对精英 / Boss 的伤害强化；
13. Time's Eternity 的正式中文名。
