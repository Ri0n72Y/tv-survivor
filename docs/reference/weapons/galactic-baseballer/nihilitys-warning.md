# 虚无的预警

> 类型：外部参考资料。
>
> 来源版本：**《银河球棒侠传说》基础版 / 《崩坏：星穹铁道》2.2（2024）**。
>
> 主数据源：Adventure Index；Game8 与 HoYoLAB 基础版攻略交叉核对。
>
> 本文先记录源武器；本项目实时类幸存者改造尚未正式收敛。

## 1. 身份

- 名称：**虚无的预警**
- 参考 ID：`nihilitys_warning`
- 属性：**量子**
- 标签：**集中**
- 最大等级：Lv.8
- 共鸣配饰：**不知疲倦**
- 进化条件：**虚无的预警 Lv.8 + 不知疲倦 Lv.1+**
- 传说武器英文名：**Time's Eternity**
- 传说武器中文名：**光阴的永痕**
- 来源版本：基础版，不使用后续《魔王篇》重平衡数据

## 2. 源武器核心行为

虚无的预警围绕敌方负面状态「懊丧」运作。

当我方命中敌人时：

1. 以固定概率给该目标施加 1 层「懊丧」；
2. 当敌人被施加其他 Debuff 时，也会额外获得「懊丧」；
3. 每层「懊丧」提高该目标受到的全部伤害；
4. 最多叠加 **20 层**；
5. 达到 20 层时：
   - 虚无的预警对该目标造成一次高额量子伤害；
   - 对精英 / Boss 额外提高 30%；
   - 普通形态随后清除全部「懊丧」。

Lv1：

- 命中时施加「懊丧」的固定概率：**70%**
- 每层受到伤害提高：**0.4%**
- 最大层数：**20**
- 20 层触发伤害：**3000% 基础伤害**
- 精英 / Boss：**+30%**

结构：

```text
我方攻击命中敌人
或
敌人获得其他 Debuff
↓
叠加「懊丧」
↓
每层提高目标受到的伤害
↓
达到 20 层
↓
虚无的预警触发量子爆发
↓
普通形态清空懊丧
```

## 3. Lv1–Lv8

| 等级 | 命中施加懊丧固定概率 | 每层易伤 | 20层触发伤害 |
|---:|---:|---:|---:|
| Lv1 | 70% | 0.4% | 3000% |
| Lv2 | 70% | 0.4% | 4500% |
| Lv3 | 70% | 0.6% | 4500% |
| Lv4 | 80% | 0.6% | 4500% |
| Lv5 | 80% | 0.6% | 6000% |
| Lv6 | 80% | 0.8% | 6000% |
| Lv7 | 90% | 0.8% | 6000% |
| Lv8 | 90% | 0.8% | 7500% |

成长结构：

- Lv2 / Lv5 / Lv8：提高 20 层触发伤害；
- Lv3 / Lv6：提高每层易伤；
- Lv4 / Lv7：提高我方命中时施加「懊丧」的固定概率。

注意：

- 「固定概率」按源版语义记录；
- 它不同于寒霜灭火器那种“基础概率 + 效果命中 / 效果抵抗”结构；
- 是否在本项目实时版中继续作为固定概率，需要在实时改造阶段单独确认。

## 4. 共鸣配饰：不知疲倦

不知疲倦只强化 `集中` 标签武器对精英 / Boss 的伤害。

| 等级 | 集中类武器对精英 / Boss 伤害提高 |
|---:|---:|
| Lv1 | 35% |
| Lv2 | 40% |
| Lv3 | 45% |
| Lv4 | 50% |

它是明确的标签型配饰：

```text
武器具有「集中」
+
目标是精英 / Boss
↓
获得不知疲倦伤害强化
```

因此它天然可以服务虚无的预警，也可以服务其他拥有 `集中` 标签的武器。

## 5. 传说形态：光阴的永痕

进化条件：

```text
虚无的预警 Lv8
+
不知疲倦 Lv1+
```

源版效果：

- 属性：**量子 + 虚数**
- 标签：**集中**
- 我方命中敌人时：
  - **90% 固定概率**施加「懊丧」；
- 敌人获得其他 Debuff 时：
  - 同样获得「懊丧」；
- 每层「懊丧」：
  - 使目标受到的全部伤害提高 **0.8%**；
- 最大：
  - **20 层**；
- 达到 20 层时：
  - 对目标造成 **7500% 基础伤害**的量子 + 虚数伤害；
  - 对精英 / Boss 额外提高 **30%**；
  - 与普通形态不同，**只减少 10 层懊丧**，而不是全部清空。

因此超武形成：

```text
20 层
↓
触发高额量子 + 虚数伤害
↓
只降到 10 层
↓
重新叠 10 层即可再次触发
```

相比普通 Lv8：

```text
虚无的预警 Lv8
20 层 → 7500%量子伤害 → 清零

Time's Eternity
20 层 → 7500%量子+虚数伤害 → 保留10层
```

## 6. 对本项目的设计价值

### 6.1 Debuff 构筑核心

它不是传统主动攻击武器，而是一个：

> **命中 / Debuff → 叠层易伤 → 阈值爆发**

的构筑核心。

它与寒霜灭火器天然形成联动：

```text
寒霜灭火器
→ 冻结 / 灼烧 Debuff

虚无的预警
→ 因 Debuff 额外叠加懊丧
```

### 6.2 固定概率与效果命中需要明确区分

源版明确写的是 **fixed chance / 固定概率**。

因此如果本项目保留这一语义：

- 不应受到效果命中影响；
- 不应受到敌人效果抵抗影响。

这与寒霜灭火器的冻结 / 灼烧正好形成两类概率机制。

### 6.3 阈值爆发属于集中攻击

达到 20 层后，虚无的预警只对该叠满目标触发高额伤害。

因此按本项目当前默认削韧原则：

- 若实时版没有另行指定；
- 该阈值爆发作为 `集中` 单体攻击，基础削韧默认 **20**；
- 仍需对应弱点匹配才实际削韧。

这里只记录当前默认基准；实时化时仍可显式覆盖。

## 7. 本项目实时化

### 7.1 懊丧叠层入口

本项目有意限制虚无的预警泛用性，不采用“所有武器命中都能叠层”。

当前只保留两个入口：

1. **角色核心武器命中目标**；
2. **目标获得新的 Debuff**。

当前角色为开拓者 / 小浣熊，因此第一个入口具体就是：

> **球棒的一次完整攻击行为命中敌人。**

计数粒度：

- 按完整攻击行为统计，不按伤害实例统计；
- 同一次球棒攻击对同一敌人无论产生多少段伤害，都最多进行 **1 次懊丧叠层判定**；
- 如果同一次球棒范围攻击命中多个不同敌人，每个被命中的敌人分别进行 1 次判定；
- 其他普通武器、召唤武器、投射物等造成的直接命中 **不触发“命中叠懊丧”**。

因此：

```text
球棒完整攻击命中目标
→ 对该目标进行 1 次懊丧固定概率判定

其他武器直接命中
→ 不触发命中叠层
```

第二个入口保持源版的 Debuff 联动：

```text
目标获得新的 Debuff
→ 额外获得懊丧
```

该入口独立于“是哪把武器直接造成伤害”，用于保留虚无的预警与冻结、灼烧等 Debuff 构筑之间的联动。

### 7.2 Debuff 入口边界

只有目标 **新获得一个此前不存在的 Debuff** 时，才通过 Debuff 入口叠加 1 层懊丧。

以下情况都 **不算新的 Debuff 施加**：

- 刷新已有 Debuff 的持续时间；
- 为已有 Debuff 增加层数；
- 单纯延长已有 Debuff 的持续时间。

击破产生的异常状态视为新的 Debuff，因此：

- 裂伤；
- 灼烧；
- 冻结；
- 触电；
- 风化；
- 纠缠；
- 禁锢；

在首次施加到目标时，都可以触发一次懊丧叠层。

### 7.3 固定概率与数值

虚无的预警完整保留源版固定概率：

- Lv1–Lv3：**70% 固定概率**
- Lv4–Lv6：**80% 固定概率**
- Lv7–Lv8：**90% 固定概率**
- 光阴的永痕：**90% 固定概率**

“固定概率”不受：

- 效果命中；
- 敌人效果抵抗；
- 专项 Debuff 抵抗；

影响。

每层懊丧易伤同样保留源版数值：

- Lv1–Lv2：**+0.4%**
- Lv3–Lv5：**+0.6%**
- Lv6–Lv8：**+0.8%**
- 光阴的永痕：**+0.8%**

最大层数保持 **20 层**。

### 7.4 20 层爆发

普通虚无的预警：

```text
懊丧达到 20 层
↓
触发当前等级对应的量子集中爆发
↓
若量子弱点匹配，则基础削韧 20
↓
懊丧清零
```

光阴的永痕：

```text
懊丧达到 20 层
↓
触发 7500% 量子 + 虚数集中爆发
↓
若任一属性匹配弱点，则按多属性规则结算一次基础削韧 20
↓
只减少 10 层
↓
允许继续叠至 20 层并再次触发
```

不设置额外触发冷却，因此光阴的永痕可以连续循环触发。

### 7.5 共鸣配饰：不知疲倦

不知疲倦完整保留：

| 等级 | `集中` 武器对精英 / Boss 伤害提高 |
|---:|---:|
| Lv1 | +35% |
| Lv2 | +40% |
| Lv3 | +45% |
| Lv4 | +50% |

它按武器 `集中` 标签筛选，不额外建立隐藏兼容列表。

### 7.6 当前状态

虚无的预警 / 光阴的永痕核心实时规则已经收敛。后续只剩实机表现、UI 层数显示和数值平衡验证，不再作为当前 Game Design 阻塞项。
