## 1. 身份

- 名称：**寒霜灭火器**
- 参考 ID：`icy_fire_extinguisher`
- 属性：**冰**
- 标签：**召唤、范围**
- 最大等级：Lv.8
- 超武进化所需被动：**踏火冰焰**
- 进化条件：**寒霜灭火器 Lv.8 + 踏火冰焰 Lv.1+**
- 传说武器英文名：**Cryoflame Thrower**
- 传说武器中文名：**待官方中文口径最终确认**
- 来源版本：基础版，不使用《魔王篇》重平衡数据

## 2. 标签

官方基础版标签：

- **召唤**
- **范围**

它是一个按自身召唤速度周期行动的全体范围攻击武器，并把输出与冻结控制绑在同一次行动上。

## 3. 源武器核心行为

寒霜灭火器会召唤一个拥有独立速度的武器单位。每次行动时：

1. 对全体敌人造成冰属性伤害；
2. 以基础概率对敌人施加冻结；
3. 冻结目标无法行动；
4. 冻结目标在其回合开始时受到额外冰属性伤害；
5. 冻结持续 1 回合。

Lv1：

- 召唤物速度：**110**
- 全体冰伤：**600% 基础伤害**
- 冻结基础概率：**20%**
- 冻结追加冰伤：**150% 基础伤害**

## 4. 等级成长

| 等级 | 速度 | 全体冰伤倍率 | 冻结基础概率 |
|---:|---:|---:|---:|
| Lv1 | 110 | 600% | 20% |
| Lv2 | 110 | 900% | 20% |
| Lv3 | 110 | 1200% | 20% |
| Lv4 | 110 | 1200% | 40% |
| Lv5 | 110 | 2100% | 40% |
| Lv6 | 160 | 2100% | 40% |
| Lv7 | 160 | 3000% | 40% |
| Lv8 | 160 | 3000% | 60% |

源资料同时给出冻结期间追加冰伤整体范围为 **150%–750% 基础伤害**；各级升级条目主要显式改变主伤害、冻结概率与召唤速度。

主要结构性成长点：

- **Lv4**：冻结基础概率 20% → 40%；
- **Lv6**：召唤速度 110 → 160；
- **Lv8**：冻结基础概率 40% → 60%；
- Lv2 / Lv3 / Lv5 / Lv7 提升全体冰伤。

## 5. 超武进化所需被动：踏火冰焰

踏火冰焰降低全体敌人的效果抵抗：

| 等级 | 全体敌人效果抵抗降低 |
|---:|---:|
| Lv1 | 20% |
| Lv2 | 30% |
| Lv3 | 40% |
| Lv4 | 50% |

它直接强化寒霜灭火器的冻结成功率，同时也能服务其他概率型负面效果。

## 6. 传说形态：Cryoflame Thrower

进化条件：寒霜灭火器 Lv.8 + 踏火冰焰 Lv.1+。

基础版传说效果：

- 属性：**火、冰**
- 标签：**召唤、范围**
- 召唤物速度：**160**
- 行动时对全体敌人造成 **9000% 基础伤害**的火 / 冰属性伤害；
- **80% 基础概率**冻结敌人；
- 冻结目标无法行动，并在回合开始时受到 **2250% 基础伤害**的额外冰伤，持续 1 回合；
- 同时以 **120% 基础概率**施加灼烧；
- 灼烧每回合造成 **6000% 基础伤害**的火属性持续伤害，持续 3 回合。

与普通 Lv8 相比，超武从单一冰属性的范围冻结，扩展为：

```text
冰属性范围伤害 + 冻结
↓
火 + 冰双属性范围伤害
+ 更高冻结概率
+ 冻结追加伤害
+ 灼烧 DoT
```

## 7. 对本项目的设计价值

### 7.1 控场型范围召唤

它与人人为我、幸运轮盘不同，核心不是投射物数量，而是周期性的全区域控制与状态施加。

### 7.2 效果命中消费者

寒霜灭火器与踏火冰焰提供了一个明确的概率负面效果构筑：

```text
武器基础冻结概率
+ 效果命中
+ 敌方效果抵抗降低
↓
冻结成功率
```

这与本项目已经保留的效果命中属性天然相关。

### 7.3 冻结与灼烧并存

传说形态同时包含冻结和灼烧，使它成为控制 + DoT 的混合范围武器。

## 8. 本项目实时化

### 8.1 范围

寒霜灭火器的实时攻击改为空间范围攻击：

- 基础作用半径：**1.5 unit**；
- 具有 `范围` 标签；
- 受到通用 **攻击范围倍率** 影响；
- 也可以受到只对 `范围` 标签生效的范围强化，例如硝烟飘带。

概念上：

```text
实际作用半径
= 1.5 unit
× 适用攻击范围修正
```

当前只固定半径与范围增益兼容性；具体视觉喷射形状 / 攻击原点仍可在实机阶段调整。

### 8.2 冻结

冻结保留源版基础施加概率，并受到：

- 攻击者 **效果命中**；
- 目标 **效果抵抗**；
- 若未来某敌人拥有专项冻结 / 控制抵抗，则额外乘入对应 Debuff RES。

参考《崩坏：星穹铁道》的标准概率结构：

```text
实际施加概率
= 基础概率
× (1 + 效果命中)
× (1 - 目标效果抵抗)
× (1 - 对应 Debuff 抵抗)
```

当前项目若没有专项 Debuff 抵抗，则最后一项按 0 处理。

实时冻结规则：

- 基础持续时间暂定 **1.0 秒**；
- 冻结期间敌人 **完全停止行动与移动**；
- 使用明确的冻结动画 / 视觉状态表现；
- 正常 1 秒冻结结束时解除冻结。

### 8.3 冻结附加冰伤

源版“冻结目标回合开始时受到额外冰伤”改造成冻结 Debuff 的周期结算：

- 结算频率：**每 1 秒一次**；
- 不在施加瞬间立即跳伤害；
- 正常 1.0 秒冻结时：
  - t = 1.0s 结算一次附加冰伤；
  - 随后解除冻结。

如果未来冻结持续时间被其他明确效果延长，则每经过完整 1 秒继续结算一次。

机制分类：

- 冻结状态属于 **Debuff / 控制效果**；
- 冻结附加冰伤属于该 Debuff 的周期性 **Additional DMG**；
- **它不属于 DoT / 持续伤害类别**。

因此：

> **惊雷冠冕等“引爆持续伤害 / DoT”的效果不能引爆冻结附加冰伤。**

这与原作机制分类一致：Frozen 的回合开始冰伤被归类为 Additional DMG，而不是 DoT。

### 8.4 踏火冰焰

踏火冰焰保留源版“降低敌方效果抵抗”的定位：

| 等级 | 敌方效果抵抗降低 |
|---:|---:|
| Lv1 | 20% |
| Lv2 | 30% |
| Lv3 | 40% |
| Lv4 | 50% |

它直接进入上面的效果命中公式，而不是改造成固定加算概率。

### 8.5 超武灼烧

Cryoflame Thrower 的灼烧保留为真正的 **火属性 DoT**：

- 基础施加概率：**120%**；
- 同样受到效果命中与目标效果抵抗影响；
- 基础持续时间：**3.0 秒**；
- 每 **1.0 秒**结算一次；
- 正常情况下在 t = 1s / 2s / 3s 各跳一次，共 3 次；
- 3 秒结算完成后移除灼烧。

因为灼烧属于 DoT：

> **惊雷冠冕等“持续伤害引爆”效果可以引爆该灼烧。**

### 8.6 当前仍未确定

- 普通形态是否完整沿用召唤速度 110 → 160；
- 主范围攻击基础削韧值；
- 冻结附加冰伤是否具有独立削韧值；
- Cryoflame Thrower 正式中文名；
- 冻结 / 灼烧是否受到效果持续时间增幅，以及具体换算。
