# 《银河球棒侠传说》基础版独立被动配饰

> 类型：外部参考资料。
>
> 来源版本：**《银河球棒侠传说》基础版 / 《崩坏：星穹铁道》2.2（2024）**。
>
> 这里记录 **不作为任何传说武器合成材料** 的独立被动配饰。
>
> 基础版 Adventure Index 共包含 **16 个配饰**：其中 13 个是武器的共鸣配饰，另外 3 个为独立被动配饰。

## 1. 擂者之拳

- 英文名：**Duelist's Fist**
- 不参与任何传说武器合成
- 功能：提高经验获取

| 等级 | 经验获取提高 |
|---:|---:|
| Lv1 | +30% |
| Lv2 | +60% |
| Lv3 | +90% |
| Lv4 | +120% |

源版定位非常直接：牺牲一个配饰槽位，换取更高升级速度。

## 2. 勤勉的嘉奖

- 英文名：**Reward of Diligence**
- 不参与任何传说武器合成
- 功能：提高浣熊代币 / Token 获取

| 等级 | Token 获取提高 |
|---:|---:|
| Lv1 | +10% |
| Lv2 | +20% |
| Lv3 | +30% |
| Lv4 | +40% |

它属于局外 / 局内资源经济型配饰，不直接提高战斗伤害。

## 3. 超剂量处方

- 英文名：**Overdosing Prescription**
- 不参与任何传说武器合成
- 功能：高风险全局增伤

| 等级 | 我方角色与武器伤害提高 | 敌人造成伤害提高 |
|---:|---:|---:|
| Lv1 | +25% | +100% |
| Lv2 | +50% | +100% |
| Lv3 | +75% | +100% |
| Lv4 | +100% | +100% |

敌方伤害提高始终为 **+100%**，不会随配饰等级继续增加；升级只提高我方角色与武器的伤害加成。

因此源版形成明确的风险收益结构：

```text
敌人伤害固定翻倍
+
我方伤害随等级逐步提高
```

## 4. 与共鸣配饰的区别

这 3 个配饰：

- 不与任何基础武器组成传说武器；
- 不需要为超武进化保留；
- 主要承担经验、资源经济和风险收益型全局构筑作用。

因此本项目后续应把它们作为 **独立被动道具** 设计，而不是继续放进“武器 + 共鸣配饰”的超武组合流程。

## 5. 本项目待讨论

### 擂者之拳

本项目已经存在正式属性：

- **经验获取倍率**

因此它可以自然映射到该属性，但是否完整沿用 30% / 60% / 90% / 120% 仍需确认。

### 勤勉的嘉奖

本项目已经存在正式属性：

- **资源获取倍率**

需要确认原版 Token 在本项目中具体映射到哪类 Run 内资源，以及是否直接使用资源获取倍率。

### 超剂量处方

需要确认：

- 我方增伤是否完整保留 25% / 50% / 75% / 100%；
- “敌人造成伤害 +100%”在同步值体系中是否直接等价于玩家受到的同步损失翻倍；
- 是否影响所有敌方伤害来源；
- 是否需要作为高风险构筑保留原版恒定双倍受伤代价。
