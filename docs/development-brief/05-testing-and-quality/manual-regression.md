# 人工回归清单

## 启动与重开

- 进入阵列无错误。
- 空白、有效、无效种子保持既定行为。
- 重开清除阵列、位置、构筑、金币、随机状态、暂停和过渡状态。

## 树状地图

- 只能进入已揭示且有连接的节点。
- 无连接旧地图仍按正交相邻移动。
- 镜头、玩家高亮、小地图和揭示状态同步。
- 高同步率成功后的额外揭示适配树状连接。

## 构筑与 Catalog

- 四把武器和六个被动顺序正确。
- 武器工厂实例化正确且无重复节点。
- 七个聚合属性数值保持。

## 阵列宝箱

- 金币不足不打开、不扣费。
- 打开奖励 UI 时不立即扣费。
- 确认时扣费一次、应用一次并标记 opened。
- 失败路径不扣费、不锁输入、不遗留暂停。

## 战斗房

- 任务、搜索、精英、Boss 的目标、计时和退出路径正确。
- 战斗宝箱打开时扣费一次，选择时不重复扣费。
- 精英免费奖励不扣费。
- Boss 结算、房间清理和胜利界面只触发一次。

## 同步 Buff

- 低信号区按 0.5 秒节奏叠加 `signal_loss`，最高层数正确。
- 离开后层数清零并移除。
- 越界断连触发伤害和额外层数。
- 稳定条件持续 3 秒后恢复同步率。
- 受伤移除 `sync_stable`。
- HUD Buff 摘要和危险边框正确。

## 清理

- 所有退出路径恢复 `SceneTree.paused = false`。
- 不残留房间、敌人、掉落、武器、Buff、奖励 UI 或过渡状态。
