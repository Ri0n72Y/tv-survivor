# 术语

| 术语 | 含义 |
|---|---|
| Catalog | 静态定义的集中发现、验证和查找层。 |
| Definition | 共享、只读的内容定义 Resource。 |
| Runtime | 某局、某实体或某次施加产生的可变状态。 |
| BuildState | 构筑与经济权威状态。 |
| BattleContext | 进入战斗的只读上下文值。 |
| BattleResult | 战斗退出时的类型化结果值。 |
| BattleEffect | 由结果携带、跨场景应用的类型化变化。 |
| Buff | 当前代码中用于同步状态的轻量运行组件。 |
| Effect | 目标通用效果模型，覆盖持续、叠层、触发和跨实体行为。 |
| Adapter | 类型化核心与旧 Dictionary 场景接口之间的临时兼容层。 |
| 堆料 | 批量增加武器、被动、词条、房间、事件等内容。 |
