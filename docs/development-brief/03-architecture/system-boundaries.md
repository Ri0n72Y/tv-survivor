# 状态与职责边界

## BuildState

拥有：武器等级、被动等级、主武器、槽位、金币、分数。

负责：

- ID 校验与等级归一化；
- 槽位规则；
- 金币支付、退款和收益；
- 属性计算；
- 防御性快照。

不负责：场景节点、UI、武器运行时、战斗房流程。

## RunState

作为 Autoload 暴露运行级状态和 BuildState 操作，并持有阵列位置、房间过渡、随机流和小地图解锁状态。

## GridScene

当前负责地图展示、输入、镜头、节点揭示、宝箱编排、战斗入口和胜利展示。职责仍偏多，是下一轮拆分对象。

## BattleScene

当前负责房间规则、实体创建、同步 Buff、刷怪、掉落、奖励、房间目标和结果构造。职责仍偏多，应逐步拆分房间流程、奖励协调和结果构造。

## UI

HUD 接收完整构筑快照和 Buff 展示快照。UI 不应直接成为权威状态修改者。
