# 内容编写规范

## ID

- 使用稳定、小写、下划线分隔的 ID。
- ID 一旦进入存档或发布版本，不应随意重命名。
- 展示名与 ID 分离。

## 静态与运行时

静态 Resource 可共享且视为只读。层数、持续时间、来源、目标、冷却和临时状态必须放在运行时实例中。

## 何时新增脚本

只有出现现有原语无法安全表达的新行为时才新增脚本。以下差异不足以单独创建行为类：

- 数值不同；
- 持续时间不同；
- 层数上限不同；
- 目标过滤不同；
- 现有 Action 的不同组合。

## 校验要求

- 重复或空 ID；
- 缺失运行时实现；
- 等级说明不完整；
- 属性数组长度不一致；
- 未知属性；
- 超过注册最大等级的奖励；
- 无法解析的引用。
