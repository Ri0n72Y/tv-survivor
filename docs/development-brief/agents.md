# Agent 规则：开发简报根目录

## 作用范围

本目录是项目当前开发状态的汇总入口。子目录负责各自模块，不应在根文件中复制全部细节。

## 必须保持的事实

- Godot 版本固定为 `4.7.1`，不得擅自降级。
- 当前代码基线是 `main@c02a0f21dcec2b7f91b9c94204ad6ceabe2bcd17`。
- 已实现、设计目标、推断和待验证状态必须分开书写。
- 不得把合并前的局部测试结果表述为合并后已通过。

## 修改规则

- 新模块应建立独立目录，并提供 `README.md` 与 `agents.md`。
- 影响多个模块的架构变更，应同步更新总览、路线图和测试门禁。
- 代码与文档不一致时，以当前 `main` 代码为准，并记录文档修订原因。

## 交付格式

每次更新至少包含：基线 SHA、变更范围、行为契约、未验证项、需要执行的测试。
