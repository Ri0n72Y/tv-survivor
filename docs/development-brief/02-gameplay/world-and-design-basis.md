# 世界观与设计依据

本文件区分“设计依据”和“当前实现”。以下内容来自项目提供的世界观与抽象探索文档，并不代表当前原型已经完整表现。

## 抽象探索依据

核心定义：玩家通过被抽象化的空间系统理解局势、选择行动、承担风险，并让选择持续改变后续局面。

关键原则：

- 空间是行动结构，不只是场景缩略图。
- 移动必须推进信息、资源、风险、结构、状态或叙事。
- 抽象界面应成为世界的感知方式。
- 结构选择改变局部挑战，局部结果反过来改变结构。
- 信息不完整用于制造判断，不用于无依据惩罚。
- 风险递增应制造继续深入与及时止损的张力。
- 重复内容需要压缩和加速。

验证循环：

```text
信息有限 → 判断行动 → 承担后果 → 局势变化 → 重新判断
```

## 世界观依据

世界观定位为日式西幻穿越爽文外壳下的宗教秩序、阶级结构、魔法污染和英雄主义讽刺。

核心设定：

- 魔素从大地、矿脉和地下结构逸散，是可使用但会侵害生命的危险资源。
- 光魔法是被教会加工、结构化和垄断的魔素处理体系。
- 暗魔法是未纳入教会体系的天然运用方式。
- 魔法的生理意义更接近排出/消耗污染，因此“魔法不是祝福，而是排毒”。
- 贵族优势同时来自适应性、资源垄断和意识形态包装。
- 教会同时承担技术集团、医疗系统、战争动员和意识形态机器的功能。

## 对玩法的潜在映射

尚未实现但可作为后续设计方向：

- 阵列界面可以解释为感知、记录、圣光仪器或污染监测结构。
- 同步率可以与污染承载、认知稳定或系统控制建立世界观关系。
- 路径深度、地下层级和资源风险可以体现“越接近大地，越接近黑暗”的空间政治。
- Buff、词条和能力不应只做数值包装，可以呈现制度化处理与天然污染的不同代价。

这些映射必须经过具体叙事和玩法设计确认，不能由工程层自行定稿。
