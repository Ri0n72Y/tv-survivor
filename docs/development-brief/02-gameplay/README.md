# 02｜玩法系统

## 结构层：抽象阵列探索

当前地图已经从固定方格移动扩展为带 `connections` 的树状/拓扑节点结构，并保留无连接数据的相邻方格兼容路径。

已具备：

- 隐藏、揭示和已清理状态；
- 节点连接判断；
- 移动动画与镜头居中；
- 小地图；
- 宝箱与战斗房；
- 战斗结果回流和高同步率额外揭示。

设计依据强调：阵列并非赶路界面，每次行动应改变信息、资源、风险、结构、状态或叙事；局部战斗和结构层需要双向反馈。

## 局部层：实时战斗

房间类型：

| 房间 | 当前目标与流程 |
|---|---|
| 任务房 | 生存计时，随后撤离倒计时。 |
| 搜索房 | 周期刷新宝箱，祭坛激活，挑战精英，再回到祭坛撤离。 |
| 精英房 | 封闭竞技场，击杀精英获得免费奖励；超时增加强度。 |
| Boss 房 | 封闭、无时间上限，击杀 Boss 后结束本局。 |

## 同步率与 Buff

同步率兼具生命、信号和战斗节奏资源。当前轻量 Buff 系统实现：

- `signal_loss`：低信号区域按 tick 叠层并降低同步率；离开后清除。
- `sync_stable`：满足稳定条件后累计时间，并在延迟后恢复同步率。

## 构筑与奖励

- 武器槽和被动槽约束获得数量。
- 武器、被动均有注册最大等级。
- 阵列宝箱在确认奖励时扣费。
- 战斗宝箱在打开时扣费，选择时不重复扣费。
- 精英免费奖励不扣费。
- 奖励校验拒绝未知、重复、降级、超上限和槽位非法内容。
