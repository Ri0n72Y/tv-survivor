# 01｜项目总览

本模块回答四个问题：项目要做什么、为什么采用阵列结构、当前做到了哪里、下一阶段应先解决什么。

## 项目目标

项目使用抽象阵列/节点结构承载探索判断，再进入局部实时战斗兑现风险。结构层负责信息、路径、资源与房间选择；战斗层负责同步率、敌人、武器、奖励和房间结果；战斗结果再回流到阵列。

核心循环：

```text
有限信息 → 选择连接节点 → 进入房间/获得资源 → 局部战斗或结算
→ 结果改变阵列、构筑和下一场条件 → 重新判断路线
```

## 当前阶段

当前处于“内容堆料前的工程收口期”。基础玩法已经可表达，但通用效果系统、复杂内容触发和大型内容生产流程仍需收口。
