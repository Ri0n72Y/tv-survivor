# 风险与待决问题

## 1. 合并后未运行

当前最大的现实风险。源代码冲突已经解析，但节点路径、类型推断和运行时行为可能仍有问题。

## 2. 两套效果概念尚未统一

现有 `Buff*` 组件与目标 `Effect*` 架构存在重叠。如果继续分别扩展，会产生双重生命周期、双重事件和双重 UI 模型。

## 3. 场景过重

GridScene 和 BattleScene 同时承担状态、编排、UI、奖励和房间规则，后续并行开发容易冲突。

## 4. 兼容层延长

奖励 Dictionary adapter 如果长期保留，新奖励类型可能继续添加临时 key，削弱类型化收益。

## 5. 地图接口双模式

树状连接和旧方格相邻逻辑同时存在。需要明确兼容周期、数据格式和测试矩阵。

## 6. 世界观尚未落到系统语言

当前原型中的同步率、阵列和 Buff 尚未正式绑定魔素、圣光和宗教秩序设定。过早命名会锁死设计，长期不绑定又会造成玩法与叙事割裂。
