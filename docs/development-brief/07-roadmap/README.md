# 07｜路线图

## 阶段 A：合并后稳定化

- 执行 import、烟测、网格测试和人工回归。
- 修复组合合并产生的解析、节点路径、类型和行为问题。
- 将测试结果写回文档和新 PR。

## 阶段 B：场景边界收口

- 奖励 UI/场景改为 `RewardOption/RewardResolution`。
- 拆出 Grid 奖励协调器。
- 拆出 Battle 奖励协调器和 Result 构造器。
- 分离网格状态变化与表现刷新。
- 分离通用战斗基础设施与房间专用流程。

## 阶段 C：Effect 最小闭环

- 选择一个真实的持续、叠层、来源明确且可触发事件的效果。
- 将同步 Buff 组件与通用 Effect 契约对齐。
- 定义事件阶段、稳定排序和类型化命令。

## 阶段 D：受控堆料

- 先增加普通 Resource 内容。
- 再增加现有行为原语的组合内容。
- 新行为原语单独评审和测试。
- 最后考虑卡牌、词条、多角色和元素反应等高复杂度系统。
